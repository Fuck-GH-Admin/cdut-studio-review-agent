## 3. 安全设计与当前接线界限

1. 全部定义为 `schemaVersion:2`、`catalogKind:'builtin'`、`status:'draft'`、`officialSchoolTemplate:false`、`policyVersionIds:[]`、`autoPassPolicy:{enabled:false}`；不创建 PolicyVersion/虚构校方 actor、确认时间、签章或远端写回。
2. `sourceNote` 标注研究非官方，`description` 在 UI 展示文本中保留“本地研究模板 · 非校方正式模板”；不提供 `approval` 输出，不配置自动 `finalize`，结束于本地人工交接阶段。
3. 116 条 criterion 为 `TemplateVersion.sections` 中的实项，metadata 保留 R→section/criterion→F/M/SRC 的可验证绑定。将研究来源 SRC 与案卷 `SourceRef` 分离。`semantic` 只做证据分析及问题建议；校本制度、签发权限、裁量/数值门槛等 73 条检查必须人工。
4. 当前 base 还没有统一 `r02-template-catalog/definitions` 注册器，因此本批无权把四份定义接入运行时发现与 V3 CanonicalPlan/Run 桥。本批专项 `validateTemplate`/绑定检查已通过；**“模板库可见、创建案卷并真实运行”尚属集成 Owner 验收项，不能称为已完成**。
5. F 字段保守使用 text（不凭论文或外校文字发明枚举与阈值）；可信身份/成绩/政策/任命/立案类数据在实际 Main 端仍必须用服务端来源覆盖不可信用户输入；材料槽 `maxCount=100` 是技术容器上限，不是校本数量规则。
