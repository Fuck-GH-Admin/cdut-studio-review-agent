# R-43｜第85号令第8条一般不予优先审查（C作者增量摘录）

适用：`G06-T01 v0.1.1`，主路径 `BR-03`，按2026-08-26国家知识产权局实施通知，以**优先审查请求实际提交日期**判断2026-09-01新办法适用，不以原专利申请日偷换。

## 规则依赖
`R-42（时间）→ R-30（第4条阶段）→ R-31（第5/6条正向事由）→ F-22（第8条因素）→ AX-08 → FC-09 → R-43`；推荐意见/最终意见仅以有权机关记录为准。

## 第8条四项分开检查
1. 分案申请 + **原申请已经准予加快审查**。
2. 被请求优先审查的是**发明**，同一申请人在**同一天**就**同样发明创造**又申请一件实用新型；四要素均需证据，题名相似不能替代同样创造的技术或法律判断。
3. 本申请/案件**在其审查程序内已经被予以**优先审查或其它加快审查。单纯请求并不等于已予以。
4. 申请人**依据第五条（四）项**请求优先审查，且有证据表明明显不具备授权前景；后者属于有权机关专业判断。

## 允许输出
- 客观记录证实命中任一项 → `PENDING_AUTHORITY` + `OC-PRIORITY-GENERALLY-NOT-GRANTED`，含义仅为**一般不予倾向**，留省级推荐部门/CNIPA依第13—14条决定；不输出正式拒绝或专利申请无效。
- 四项在可用证据范围内均否定 → 此规则局部 `PASS_EVIDENCED`；不等于国家已给予优先审查。
- 关键事实未知 → `CONDITION_UNKNOWN`；国家数据不可达→`SOURCE_UNAVAILABLE`；同样创造/授权前景专业争议→`MANUAL_REVIEW`。
- 第五条（四）项的**免推荐意见**来自第11条，不能当第8条一般不予的明文豁免。

## 作者可复算最小事实（仅模拟，不是D/E评测）
两个虚构案例均为2026-10-10优先审查请求，均有发明A（申请人大学甲、申请日2026-09-20，已进入实审而尚未首次处理）、有效第五（一）项理由及合规请求材料，且第8条其它三类因素均可证为假。唯一变量：
- Case A：`F-22.sameDayTwin=false`（没有同申请人同日同创造的实用新型）→本规则**局部无第8条不利因素**；仍待主管机关决定。
- Case B：`F-22.sameDayTwin=true`（同申请人大学甲，2026-09-20同样创造的实用新型U）→第8（二）项命中，**一般不予优先审查风险**；绝不自动拒绝国家普通专利申请。
- 仅同日、同标题但「同样发明创造」无法确证→ UNKNOWN/人工复核。
