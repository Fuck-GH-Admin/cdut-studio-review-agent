## 适用性说明

- SCHOOL_CONFIRMED 只指能从成理官方渠道核实**所述渠道**确实有该表述；不自动证明无修订或所有渠道通用。CE/PR 直连若返回412，以官方搜索索引文本且注明限制。
- CROSS_SCHOOL_REFERENCE 绝不能提升为成都理工当前硬性拒件标准。
- OFFICIAL_GENERAL 是法律/教育部/上级制度文本，仍需按事项及主体适用；DESIGN_ASSUMPTION 只是一项安全设计建议。
- POLICY_PENDING 具体包括：成理2026普通非卡类失物窗口、代理/出库授权，本校普通信箱再办接口及管理时效。未核事项只允许条件关闭或人工确认。
- 本表H风险**事前分母22/22，逐一形成源事实结论**；可确定本校具体细则的比例远低于22，不等于22项都 SCHOOL_CONFIRMED。M事前8种机制均可作设计挑战，但源义务无法充分核实，按PARTIAL计；L事前4种机制已做结构性检查，但来源义务全集分母未知，禁止报告统计意义抽检比例。

## M风险机制（8/8已核方法，未声称8/8校规已核）

| M规则 | 机制 | 事实层判断 |
|---|---|---|
| T02-M01 | 保管状态变化 | 领取前应由有权方确认物品未被交付/转移；未知不能自动交付（政策参数待核） |
| T02-M02 | 现场身份 | 现场原件核验可以是后置步骤；不能要求线上预审有现场人员签字 |
| T02-M03 | 冲突及补证 | 同名/同色/公开照片证据弱，冲突应保持待核，申请方可补合法证明 |
| T02-M04 | 不同场馆 | 不同保管方权限与保管手续可能不同；须配置而不能默认保卫处唯一负责 |
| T03-M01 | 渠道主体适格 | 校级、学院、教务渠道受理对象不同，按具体原文限定，不能扩大 |
| T03-M02 | 撤回窗口 | 仅山东案例支持学校操作前撤回，成都理工本地渠道不可强制宣称 |
| T03-M03 | 重复与新事实 | 新事实的再提诉求不等于恶意重复，是否接受重复需渠道确认证据 |
| T03-M04 | 分办与跨部门 | 提议转办≠承办部门已受理，不可自动标为学校完成 |
