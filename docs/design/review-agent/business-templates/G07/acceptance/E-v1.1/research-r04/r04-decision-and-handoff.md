## 1. 本轮确有信息增量，但绝非确认“城市无票房费可报”

**有证据的肯定（F + O）**：
1. 2025-04 官方《“只跑一次”财务事项清单》对“无法取得住宿票据”的材料要求文字较宽；同月官方《财务报销应知应会手册》科研差旅篇明确给出“野外艰苦地区”这一限制。**不能把前者的宽表述直接提升为城市房费免正规票据的正式政策。**
2. r03 所定位的旧 C v0.1 “一般无票材料槽与城市有偿无票执行路由未明确闭合”在**新候选 C v0.1.1** 中，已通过 `BR-07-U → MS-06 → R-34` 获得明确的 **人工询源/房费待核路径**。作者分支 `b9ffd7b358f46ff271a479f8e27da6818986c388` 的源说明和规则矩阵均能静态复核。**旧 v0.1 仍维持为历史原件；r03 静态缺口结论不被倒改。**
3. 新 v0.1.1 还有两处小型静态契约待办：`SOURCE_PENDING` 与 `CheckState` 命名空间未明确映射；`R-17` 解释里仍写“明确0房费”，不适合不分经济事实地应用于实际付费无票野外案。详细行号和反例见 `r04-evidence-and-reproduction.md`。

**被证据排除（否定）**：不能主张 `MS-06` 完全不存在；不能声称新 C 仍无城市收件/人审通路；不能把城市签字说明视作已获财务批准；也不能凭旧纸质指南判 2026 现行付款，或把保留待核状态说成 D/模型运行失败。

**唯一仍关键的政策 U**：**2026 年有效的科研差旅规定是否允许“获批城市科研出差、已实际付费但客观无法取得正规住宿发票、说明+项目负责人签认+学院审批”情况下的住宿费申请和核定？** 如果允许，其法律/校规依据、金额证明、补票优先顺序和可签批岗位是什么；如果不允许，说明与签批可被用于哪些非住宿费的差旅费用佐证？是否存在后发调整 2024〔20〕条款的文件？

## 2. 材料槽与判定通路（设计追踪，不代表校方许可）

```text
旅后 G07-T02 科研差旅 + 适用版本待定位
 ├─ 科研任务、出差人与预算 → R-02/R-04/R-05（各有权事实）
 └─ 住宿费用行 → 住宿发生/付款真实事实 + 房晚 + 票据状态
      ├─ 合法住宿发票 → EV-05 → R-13；若发票明细不足 → R-14
      ├─ 真实免费包宿 → EV-06 → R-15 → 确认无自付房费时才记0
      ├─ 艰苦野外无票 → EV-07 → R-17（仍需条款有效+有权签认）
      └─ 城市科研已付无票 → BR-07-U → MS-06 → R-34
                                 → SOURCE_PENDING[来源诊断元数据]
                                 → POLICY_UNRESOLVED/HUMAN_REVIEW[检查态]
                                 → PRECHECK_PENDING[住宿费用行]
                                 → AMOUNT_PENDING[金额未计算]
  MS-06材料组合: 有效情况说明 + 项目负责人签字 + 学院审批
                 + 实际住宿/付款佐证 + 适用政策核验（并非等效发票已成立）
  其他交通等费用行由各自凭证与有效政策独立审
  任何住房行预审 ≠ 正式核销额 ≠ 财务已付款
```

**材料槽定义建议**：`MS-06-A`（同一 `MS-06` 内条件组，非新全局材料编号）应能容纳“有效说明、项目负责人真实签认、学院有权审批记录、真实房晚/支付及无票原因”。前 3 个是 2025 清单列举的有条件佐证材料，支付与住宿证明仅用于确认经济事实，**不被默认视为校方已认的房费税务替代**。如果现行规则不允许城市住宿无票列支，仍保留事实受理/政策咨询结果，不以机器冒充财务决定。
