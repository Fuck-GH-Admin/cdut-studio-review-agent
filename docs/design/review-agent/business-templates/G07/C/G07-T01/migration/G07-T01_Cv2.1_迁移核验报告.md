## 3. 发现的v0.1既存交付缺口与最小修补

### FMT-01｜Markdown表格相邻行被空行拆开

- **原有问题**：v0.1母版中**634处**单个空行夹在两个 Markdown `|` 表格行之间。标准Markdown表格解析器因此只识别**50行**表格记录（大多只识别标题），而不是应有的**684行**；32条规则正文等实质信息通常呈碎片化普通段落，不利于验收阅读。
- **修补方式**：只删除上述634个空行，保留原有全部非空行的顺序、文本、空白字符和ID；没有增删字段、规则、例外或来源。修补后仍是**50张表格**，行数从50增至684。修补文件独立命名 `layout_fix/G07-T01_正式业务模板_MD_v0.1.1_仅表格排版修补.md`（SHA-256 `39cdd8f00efb51fd54ea1dc728fb1bde924f084f459b6a40d37dd2cafc312def`）。
- **版本治理**：业务语义依然v0.1；本次排版修补标识v0.1.1，旧v0.1母版全文及哈希保留在 `originals/` 和历史ZIP。E建议使用v0.1.1阅读，以v0.1对照逐非空行一致性。
- **影响边界**：原矩阵、自检、模块候选未发现同类渲染问题，全部保留。此问题是旧版真实格式缺口，不是因C v2.1新增业务需求。
