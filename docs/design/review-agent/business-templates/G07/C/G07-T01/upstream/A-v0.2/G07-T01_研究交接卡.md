## 1. 模板的唯一审核目的

已实际发生的活动、竞赛与科研常规直接费用（非差旅、非合同采购）的票据及预算关联审核。**只做该目的的申请材料审核/前置风险识别，不代替有权部门最终签批、实际记账与付款**。

## 2. 业务卡

- **用户易理解名称**：活动、竞赛与科研直接费用报销预审。
- **原四项/新来源**：G07-01。
- **申请人、代办和最终审批主体**：支持学生个人垫付申请、组织者/教师经办，负责人/财务作最终签批。
- **典型申报事项和主干情形**：直接费用核销；报名费、作品邮寄/展示印刷、学科竞赛/科研日常小额费用、科研版面/专利费用条件分支。
- **申请材料/证明材料组合的初步入口**：活动通知/预算、报名或参赛名单、发票、付款流水或对公凭据、成果与奖品签收（条件）。这里仅为A阶段初始索引，不是正式完整必需清单。
- **分支线索**：赛事统一对公 vs 学生垫付；阶段参赛；专项预算；活动礼品与非允许费用。
- **边界**：不代替差旅/采购合同/专家酬金/举办会议审查。

## 4. B阶段必须深调的具体问题

1. **材料粒度**：区分报名费/活动材料/宣传及邮寄、作品材料、专项活动与非允许项目；学生垫付与对公支付到底需要哪些原始证明？
2. **极端情形与合法例外**：上一届/本届、赛事多阶段、一事一报、发票抬头与缴款人不同、奖励品签收、票据税务查验缺口
3. **相邻模板与审核责任**：活动费用不一定等于有权批准采购；对G07-03采购按品目金额切分，跨差旅/会议主办/专家发放需路由
4. **成都理工大学现行校本规则**：原始表单、2026智能报销字段、预算项目和角色权限；页面检索能证的与不能证的逐条分开。
5. **跨学校**：至少再找两所不同高校公开申请表/办事指南做交叉验证，写每条材料的触发条件、替代证明与缺证后果；高校不同金额不可直接择高作全国强制。
6. **审查输出**：区分可受理、待补件、仅能材料预审、需要权责审批、无法核实外部台账；不要把AI识别结果自动提升为有权批准。
