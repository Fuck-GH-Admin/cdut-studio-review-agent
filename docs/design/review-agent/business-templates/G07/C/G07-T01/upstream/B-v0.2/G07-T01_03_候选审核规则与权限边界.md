# G07-T01｜候选审核规则事实与权限边界（B阶段）

> 目的：供后续C研究“应描述哪些可审核事实”使用。**本表不是正式规则JSON、不是CDUT当前已核准规则引擎，也不是本会话给每个案例下金标**。每条规则区分来源事实、研究建议和“未知”状态；独立ID `Q-xx` 是B阶段候选。

## 0. 证据核验优先级和判断动作

**优先级不只看是否扫描清楚**：适用学校、年份、部门制度及项目合同（判断规范）→ 学校经费授权/已签发审批底账、税务发票状态和校财务历史（判断事实）→ 官方通知/赛事名册/合同/编辑部函件 → 申请人上传原件与截图 → 自述/聊天/网站营销文案。**正式第三方原始证据与权威学校底账分别承担不同作用，不能简单以图片清晰度排序权威性。**

研究建议动作：`scope_route` 非本模板转办；`precheck_candidate` 初步满足可移交有权审批；`supplement_required` 已知必需事实缺失；`authority_review_required` 材料间矛盾或专业判断；`external_verification_pending` 要求接口而接口不可达；`not_eligible_evidence` 已有可信依据证明费用行不符；`partial_precheck` 某些费用行可预审、另一些待核。最终付款与财务否决均必须有权部门决定。

## 2. 绝不能自动下结论的事实

1. **税务票据真伪与红冲状态**：需要财务/税务接口；原生OFD/PDF提取到一串票号不等于验真。[CD-B01]
2. **往期是否报过/已获赔偿**：需要财务历史账及退款信息；同赛事名称、同卖家、同金额不是充分证据。[EX-B01]
3. **资金余额/允许科目、人员有无授权**：需要项目/预算/身份系统；无法联机≠提交人违规。[CD-B01][CD-B02]
4. **活动是否真的举办、奖品是否发给某人、订单是否真实履行**：若凭证相互矛盾，应由组织部门核验，不因宣传图片生成事实。
5. **科研学术合规、专利权属、合同或供应商是否合法**：T01只看关联的权威证明/转相邻业务，不应重复出具专业结论。
6. **真正的会计账务核算和支付**：审批链与支付状态由财务执行。[CD-B01]
7. **校本2026新系统“无票报销”的例外条件**：仅确认有官方目录入口[CD-B08]，**规则正文未获得**，不准以猜想放宽或加严。

## 3. 可能互相冲突的条款，怎样决定

- 同类费用，**CDUT2025活动一次报** vs 常州2026阶段多次报：先看学校与活动/赛段，再查当年有效本校政策，不做全校强制归一。[CD-B01][EX-B01]
- 校本科研“专利费用申请/年费”附预算任务书或盖章合同的分支，CDUT2024流程与2025清单措辞可能不完全相同：不应只从2025 PDF异常排版部分创建不可修订的必填规则。[CD-B01][CD-B04]
- 2025纸质旧预约签批 vs 2026智能报销：`policy_effective_from`及旧预约取消通知优先，旧表单名仅作为材料事实线索。[CD-B02]
- 北师大心理学部单价/人次限制、常州报名费流程、东北财经大比赛结束要求都**不是CDUT的生效法规**。[EX-B02][EX-B01][EX-B04]

## 4. 需要C阶段逐条决定的构造问题（非最终规则）

- 是先按**费用行类型**路由，还是整份申请按主业务路由，再拆分？建议保留一个活动汇总但强制逐行`line_scope`。
- 活动人数/餐食部分签收不足时是补正全部还是预审已核部分？需要本校会计处理能力、预算准入配置；B阶段仅提出两种处理。
- 授权代办的最小证据是什么？必须从2026角色系统读取；不可把学生签字设为项目审批人的替代。
- 同票据已部分报销时自动建议可报剩余额是否可行？财务账簿没有开放时需要`external_verification_pending`。
- 非差旅票据丢失例外和2026无票报销的衔接，不得预先在C模板设不可修改的固定路径。

**责任分界**：Q表仅为事实和适用性的审查清单，真正资助/合同/出差/用章/会计/银行支付均由相应组织与专业岗位决定；不生成“自动放款”规则。
