# G07-T01｜活动、竞赛与科研直接费用报销预审：独立业务深调研

> B阶段独立研究 · v0.1 · 2026-10-12 · 成都理工大学证据优先、其他高校交叉验证
> **范围锁定**：由A阶段 `G07-T01_研究交接卡.md` 及 `G07_02_统一模板目录与边界.md` 确定。本次研究不重排G07其它六套目录；原A目录仅作为历史研究基线，现行校规以核实的校方制度和通知为准。

## 0. 研究判定及结论

G07-T01解决的**唯一审核目的**是：对**已实际发生**的学生组织、竞赛及科研的**直接费用**逐条核验其业务关联、合规票据、支付、经费/预算、身份与授权，给出“材料预审是否可移交财务以及费用行暂拟可核销金额”。它不签发最终审批，不假定学生自动具备经费支配权，也不直接确认银行已付款。**费用类型相同并不能证明同一项业务，反之单次活动含多类费用行也不能塞给一个审批入口。**

研究结论：**可进入C模板研究和D测试研究，但带校本现行规则配置缺口**（最终状态在05）。绝大多数**材料类型和条件路径有公开校本证据**；2026智能报销的字段、角色权限、发票状态和适用金额细则仍需当作配置/系统核验，不能凭2024/2025历史清单宣布其2026仍然强制。

### 0.1 相邻业务必须正确分流

| 本人提交的支出 | 是否留在T01 | 边界及下游责任 |

## 2. 真实流程：四层审批和一个执行链

1. **业务准备/事前必要审批（有条件）**：活动组织/批准、预算和可用经费；北京师范大学心理学部和中国石油大学（北京）社团专项对活动前审批有明确要求[EX-B02][EX-B07]。本校T01并非所有科研版面费都有同样的活动事前审批表。
2. **费用发生与原始资料生成**：活动实施、赛项报名、缴费、领用/领取、论文录用、专利受理等；必须明确文件来自谁，发生在何阶段。若费用尚未发生，只能预判“预算/申请”，不是T01报销案件。
3. **学生或教师填报核心申报材料**：报销单/费用行、说明及必要签字；学生可能是付款人/受益人/文件提供人，但校方的财务经办与最终批准权另设。江苏信息职业技术学院明确指导教师办理，委托学生代办仍由教师签字负责[EX-B05]；常州工学院则允许学生垫付后款项转入学生账户[EX-B01]，不能跨校视为同一权限事实。
4. **系统材料预审**：基于学校/年度/经费类别/付款方式确定条件必需，提取事实、金额与多文件关系，返回候补、待确认、分项预审意见或应路由其它模板。
5. **有权部门复核→会计核算→出纳支付→归档**：即使材料预审无异议，也不代表负责人和财务最终批准，或钱已到账。2025财务清单将预算、会计核算、资金结算设不同部门[CD-B01 P1]。

建议生命周期 `draft → submitted → evidence_check → request_supplement | needs_authorized_review | precheck_finished → unit_approval → finance_approval → payment_pending | paid | returned → archived`；`withdrawn/rejected/expired`为旁支。**以上字符串是数据模型建议，不是原样摘录CDUT接口。**

## 3. 人员和对象：分开建关系才能防止错杀

- `claimant`：申报提交人；可为学生或教师。**校方是否允许本科生独立点“提交”需校本角色核验**。
- `expense_owner`：实际垫付方/单位对公付款主体；和`claimant`可能不一致。
- `beneficiary`：实际费用受益（参赛团队、活动参与人、科研项目）；不一定是付款人。
- `event_organizer / event_approver`：活动主办部门与事前审批人，可能是两种主体。
- `fund_controller / project_lead`：经费负责人，按照授权对经费和签名负责；不一定是学生导师或赛事队长。
- `invoice_issuer`：票据开具者；`actual_payee / payment_recipient`：交易收款人/报销款收款人，需查合法代收/代垫关系。
- `finance_reviewer / fund_disburser`：有权会计核算及资金执行主体；系统只读取记录或转人工。

现实的一对多/多对多：一笔费用对一个活动、多张票对应一个订单、同一个发票包含不同预算科目的多费用行、一笔竞赛报名费团队多人平摊、省赛/国赛有不同阶段、同一张证据支持多个费用行但不代表可重复报销、一个申请若干费用行可产生不同核准金额。[CD-B01][EX-B01][EX-B02]

## 5. 风险等级与处理原则

- **明确费用与活动无关、票据在可信平台显示已撤销且无合法冲销、申请人明显无权使用预算**：可标为高风险并建议不予核销/转有权部门；不在材料预审阶段自行宣布资金追责。
- **关键信息缺少可补，存在等效材料路径**：先列缺什么事实，而不死板列具体一张纸。
- **外部台账/票据查验不可达**：给`external_unverified`，不能归责于申请人。
- **两份正式证明不一致/发票具明显篡改迹象**：标证据冲突和人工复核，保留原件/文件哈希；OCR乱码不等于伪造。
- **部分费用合规、另一行不合规**：逐行处理，可建议核销合规部分；最终财务同意与否留权责部门。
- **隐私**：报销收款卡号、身份证号、手机号只保留匹配所需字段/token；报告展示脱敏信息。

## 6. 研究范围之外仍能影响T01的条件

采购规则（T03/T04）、科研预算调整（T03相邻/主管科研）、是否准许使用某项目报会议注册/车票（T02）、奖励发放（T05）、校级竞赛认定（S06）、外事或国际知识产权审核（G05/G06）均可能作为**已取得的前置授权或待校本配置**。T01不得因为外部授权节点未到而伪造“一定通过”或“一定违规”的结论。

**B阶段产物定位**：其余01—06文件详述场景、字段材料、规则事实、来源、缺口以及后续两条独立任务交接。本文不包含正式模板Schema或Gold答案。
