## 1. 唯一确认的任务范围

- **模板编号**：`G07-T01`
- **正式工作名（A阶段目录）**：活动、竞赛与科研直接费用报销预审。
- **唯一审核目的**：已发生的**直接费用**与适用经费/活动、票据、支付及有权审批事实是否匹配，计算逐项**暂拟可核销范围**并给出材料问题；不授予资金批准权。
- **业务边界**：差旅T02、采购事前T03、委托加工/采购结算T04、助研/专家T05、主办会议培训T06、借款冲账T07、科研成果认定G06。
- **用户主体**：学生可作为参与人/垫付款人/资料提供人；能否**独立系统发起**由学校权限配置；项目负责人、学院、财务的真实角色不与学生混用。
- **阶段判定**：本次为B阶段研究完结，可交给C+D；绝非模拟案审核结果。

## 3. 提供给C会话（完整MD模板）的精确工作要求

1. 继续用**单模板多条件分支**表示费用类型、活动/赛项、预算来源、学生垫付/对公、金额、时期及附件等条件；各条件下申请人应当看到明确、尽量少的必传材料。
2. 使用**申报事项、申报材料、证明材料、可信学校底账/接口**四类数据；任何字段均标触发前提、必须形成阶段、合法替代、缺失建议、校本来源及有效期。
3. 不将G07-T03/T04的采购合同审批、T02差旅补助和T05酬金纳入本模板的核心审批输出；跨域仅接受正式引用/状态。
4. 将CDUT2025所有具体限额先标成**受版本约束的校本候选条款**；除已明确2026新制度事实外，不能宣传为2026现行通用阈值。
5. 不同结论可以并存：某费用行可预审、另一个待补、另一个需要人工/外部核验。最终会计审查与银行支付是后继状态。
6. 需要确认本校新系统权限、票据例外、科研纵向专利约束时使用`school_rule_config_pending`，不凭空“严格审核”。
7. 如果发现T01含论文专利直支使规则过于复杂，可以**报告调整建议**给G07主会话，但不能另行开平行校本模板目录。

## 4. 提供给D会话（独立测试设计）的精确工作要求

1. D应该独立根据**同一份B事实基线**建立**一所虚构学校、单一生效版本且内部自洽**的报销审核规则；真实高校资料只验证情境类型，不可拼凑不同学校的强制金额标准。
2. 测试至少覆盖S01-S18和CF01-CF24所体现的有效、必拒、待补、替代、例外、冲突、权限、分项计算与不同阶段，另重点验证学生代垫、对公付款不缺个人流水、录用未见刊、票据遗失可补、跨期重新填单和角色代办。
3. 上传资料**不得出现**“应驳回”“资料与下一页不一致”“这一张为错误”等标准答案标记；错误解释、规则命中、正确金额和复核原因都只能存在独立金标包。
4. 原本是扫描件、纸票、纸质奖品签收或带公章照片的附件，先图像化再嵌入PDF并核对无可直接提取文字层；原生电子票、DOCX/网页或校内导出表可保留原始格式。
5. 需要**虚构财务台账镜像**测试发票真伪状态、重复核销、授权与余额，否则正确答案应包含“外部尚未核验”，不能臆断真假。
6. 评分需要分别统计`item_scope`、`triggered_document`、`missing_facts`、`supported_amount`、`human_review`、`line_decision`、`evidence_refs`及`privacy_leakage`；特别检测误杀率、漏放率和“早于应形成时间索要材料”。
7. **独立先设计测试案再验收，不借用C阶段写出的预期案例答案或模型自身上一轮判定。** C阶段可提供最终规则文件作为被测审核依据，但金标不得与材料混装。
