## 自查发现并已在母版修订的设计问题

1. B阶段Q-20“预算科目匹配”对横向包干误杀：新增F-59/F-61与R-29，并在R-20明确按资金管理方式先决定是否真的存在细分科目。
2. 对纵向非设备费调剂是否必经学院审批的过度假设：新增F-60、R-30，仅核经费负责人依法授权及项目限制，设备费走有权项目/采购流程。
3. 风险线索被误当已违法：新增F-63/R-31，把同商户反复交易、合同时间冲突设为`risk_flag`，要求实质证据与有权核验。
4. 学生垫付与学生签批混淆：R-21/R-28/R-32将经办、收款、经费责任人、最终会计分离，CD-B15校区职责不推导个人权限。
5. 申请尚处于计划阶段时原逻辑可能索未来发票：ST-01与R-26增加NOT_YET_MATURE/路由，不误判缺件。
6. 部分可核/部分退款/不同事项混报：按稳定费用行与资金分摊聚合，金额不能已核总额与待核金额相加。
