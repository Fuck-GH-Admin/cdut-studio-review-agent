# G07-T04｜独立D阶段测试对接说明（仅公开业务契约）

> 本文件向 D 测试作者提供**可观察的业务语义**；不包含独立测试金标、隐藏样例或真实付款信息。C作者不得阅读或修改D金标。测试作者应独立构造事实材料与答案，不能直接用本母版的作者样例反推隐藏标准答案。

## 最少需要对接的结构

1. 模板唯一ID：`G07-T04`，母版版本`v0.1-C-20261012`，允许银行付款阶段明确外部系统接口未知。
2. 案件由多个`payment_action`构成；每动作一个当前stage和若干`payable_line`。同案存在不同货物、服务或币种，需要逐行事实判定。
3. 申报事项、申报材料、证明材料与可信底账四层严格分离。D的封闭测试可以为学校R级记录构建模拟接口/只读账簿，但需**明确授予可信级别**；学生上传的所谓“后台截图”不能直接等价R级。
4. 能观察的结果包括：每行材料状态、证据状态、业务预审意见、来源引用、规则ID、问题码、下一个有权岗位和**不构成正式批准**的候选金额；审批与银行执行轴独立。
5. 策略可配置：一所虚构学校需写清采购品类/阈值含不含等号、合法预付、验收资产分支、电子票据/税务查验路径、同笔不同币种与授权有效期。不能把CDUT待确认政策当确定金标依据。

## 观察边界与敏感内容

- D可以用图片型PDF、OFD、合同页、设备验收扫描、电子发票、Excel、校内收费通知和模拟银行记录；证明原件是纸件时应先渲染成图片再嵌PDF，不能把“同另一页不一致”写成申请人附件内的提示。
