# G07-T07｜字段、材料槽与证据关联矩阵

> CDUT Studio｜G07-T07｜B阶段单模板深度调研 v0.1｜核验日 2026-10-12｜研究材料，非正式校规/生产规则/测试金标。

## 0. 说明：不是“全字段都必填”的万能表

- **申报事项**：本次操作（借入/凭票冲账/现金还款/延期/冲正）、借款用途、申请金额、涉及的借款号及分配关系。
- **申报材料**：借款申请书/网上借款单、说明、拟冲账金额分配表、延迟申请与授权性确认。
- **证明材料**：出差/实习/外事事前批准、文章录用通知、合同付款通知、费用票据、还款银行回单等实际由申请人持有或提供的证据。
- **可信学校底账/接口**：项目有效预算/余额、借款实际放款与未冲余额、审批权限表、财务入账记录、银行到账、历史核销、已生效逾期处理。**不可由学生截图冒充内部可信台账**。
- 必需性采用条件表达式 `when`，例如 `F-19=国内差旅` 才会触发 `M-03`；`stage=before_disbursement` 不应触发 `M-12`。表中来源ID在04中可查原始链接。

## 3. 多实体关联、主键及冲账金额分配建议（B3，仅研究建议）

| 对象 | 建议主键 | 一对多或多对多关系 | 不能合并的事实 |
|---|---|---|---|
| `loan_application` 借款申请 | application_id | 一单可映射一或多业务明细 | 单据创建≠实际债务已拨 |
| `loan_account` 借款债务 | borrow_id + fund_id（如学校原核销号需完整组合） | 一笔借款可多次冲账 | 余额取会计账，不取学生自报 |
| `loan_obligation_person` | borrower_staff_id | 一人可有多笔旧借款；一笔可以多人受益但只一个/制度允许责任关系 | 登录学生不是借款责任人 |
| `fund_authority` | fund_id + effective_from | 负责人可变更，须按审批时点选任职 | 负责人签字的图片不代表系统已批 |
| `expense_line` | expense_id + line_id | 一笔借款可抵多笔费用；一笔费用与多借款分摊 | 同一费用不能重复抵足额 |
| `offset_allocation` | offset_id + borrow_id + expense_line_id | 显式金额边；多债务、多费用构成二部图 | 不能单靠两个文件总金额相等就认定合法 |
| `cash_return` | cash_return_id / bank_txn_id | 还款记录可先银行转出再财务入账 | 回单与会计销账是两事件 |
| `accounting_entry` | voucher_id + entry_type | 冲销/冲正需要引用原凭证 | 不准覆盖旧有会计历史 |
| `policy_record` | school_id + policy_version + event_type | 旧借、当前还款可受不同制度 | 不把2024旧操作当2026强制 |

## 4. 条件/等效证据组（不强迫每份全传）

1. **借款用途事实**：合同/协议/缴费通知中任选可证明合法付款义务的符合学校认可原件；差旅/实习/国际按L01专门附件触发。
2. **权限证明**：校内OA有效审批记录优先；旧纸表若适用则需本人签及授权审批；新版具体电子签验真必须由系统提供。
3. **旧借款余额**：L2权威借款台账，不能以用户上传另一页写着“还剩0元”替代。
4. **现金归还**：转账回单可以证明转出；银行到账或学校会计入账才能证明实际清账，两者属于不同证据层。
5. **费用合法性**：T01/T02/T04/T06分别形成其费种合法性审核结果；T07只读对应结果和关联文书，不重复向所有申请索要全部费用类别的附件。
6. **身份证与账户**：审核时使用脱敏唯一引用字段；完整银行账号、证件号应只在授权支付系统保存，不作为模型输出的常规字段。

## 5. 状态字段与缺失动作判别

| 状态 | 是否必有放款记录 | 是否必有冲账费用材料 | 正确输出 |
|---|---|---|---|
| 申请草稿/提交待审 | 否 | 否 | 可以给材料缺口及资格建议，不能报“借款批准” |
| 审批通过但银行未拨款 | 否 | 否 | 已批待支付，不形成“已拨”债务 |
| 已拨待业务发生 | 是（M-10） | 否 | 监测期限，不按无票拒绝初始借款 |
| 已发生拟冲账 | 是 | 是（M-11/M-12） | 分费用行候选冲账金额，等待财务入账 |
| 银行还款已发起 | 是 | 否 | 等待财务到账和匹配借款ID |
| 部分抵借与余款待还 | 是 | 对已抵部分需 | 保留未清余额 |
| 财务会计已抵账/全归还 | 是 | 有归还或费用记录 | 依据凭证结案，保留历史 |
| 已冲账发生会计冲正 | 是 | 涉及冲正凭证 | 重算未清余额并开启清理 |
