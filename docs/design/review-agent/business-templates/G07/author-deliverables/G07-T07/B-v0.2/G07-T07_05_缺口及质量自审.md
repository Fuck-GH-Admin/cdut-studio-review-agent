## 2. 双向反事实审计（B6，不是盲测答案）

| 反事实组 | 合规或应留待核的一侧 | 非合规或不可直接批准的一侧 | 为什么不能只有“缺材料就驳回” |
|---|---|---|---|
| CF01 正常借款 | 有明确经费号、用途、教师责任、事前批准 | 只写“先借1万元以后再说”且无业务事实 | 用途可补，不能因还没有未来发票而拒绝初始申请 |
| CF02 学生代办 | 学生登录、教师正式借款且有代理授权 | 学生把本人学号填为债务责任人 | 两者权限不同，参见本校2017FAQ[L02] |
| CF03 大额明细 | 2025国内出差旧清单恰好50000元 | 同旧标准借50000.01元但不提供负责人签字明细 | `>` 与 `≥` 不可混淆；现行年度规则尚未知 |
| CF04 未触发用途附件 | 实习借款有实习前批准而没有会议通知 | 国内差旅借款根本无出差/行程依据 | 不能要求两类附件同时齐备 |
| CF05 合法等效 | 其他用途有正式合同**或**付款通知证明义务 | 只有学生自己写的无单位确认付款要求 | “或”的等效材料不可错判为“且” |
| CF06 事前与事后 | 已批准借款待支付、没有报销票据 | 借款已经拨付却声称仅因系统已批就不需结清 | 未发生材料不是申请缺件；放款后责任随阶段变化 |
| CF07 资金到账 | 银行回单已发出但待校方银行确认 | 上传截图自称已归还完毕，校账仍未入款 | 银行发起、入账和会计冲账三种状态不同 |
| CF08 合法部分冲账 | 已借10000、合规发票7000、另3000待还 | 用7000合格凭证标原10000余额归零 | 按分配金额记账，不整单误杀或全放 |
| CF09 超额费用 | 借5000、合规发票6000，5000抵借另1000付款待审 | 直接把债务余额冲成负1000 | 额外费用走各费种报销流程 |
| CF10 多对多 | 两份原借款抵两笔独立合法费用 | 同一费用行被两借款全额重复抵借 | 必须查 expense_line_id 与 borrow_id 分配表 |
| CF11 外校期限 | 河海、湖南或西北政法的1月/3月等条款 | 用外校三个月判CDUT2026材料逾期 | 校规适用对象不同，法律和人事责任不可外推 |
| CF12 书面延期 | 财务正式批准延期，原期限到后仍属新期间 | 学生聊天说导师同意、无正式延期批件 | 有权批准不能凭自由文本建立 |
| CF13 报销版本 | 2026新系统有效OA而没有2024旧预约单 | 明明要求线上批准却只传手写老师同意 | 新旧操作方式不同，审批事实要独立核验 |
| CF14 已否决 | 财务正式否决并给出有效记录 | 仅存在“待审”状态却被模型说不合格 | 必须区分等待批准与正式不予批准 |
| CF15 争议事实 | 两份支付凭证时间冲突时待银行核对 | 直接认定其中一张造假且扣罚 | 图像材料无法最终鉴伪 |
| CF16 责任越界 | 费用已由T02核准、T07只查抵债关系 | T07自行宣布会议或差旅专项批准 | 其他模板有独立审签权 |
| CF17 暂付变更 | 原合同取消后提交正式退款及新用途批件 | 取消项目仍用旧未履行合同票据核销 | 非相同费用不能无依据抵借 |
| CF18 现金与费用混合 | 部分票据冲账、部分现金归还，同借款关闭 | 重复把返还金额和报销额各抵一次 | 余额必须跟银行到账和会计凭证一致 |
| CF19 委托权限过期 | 委托在本次提交时仍有效 | 同一学生拿上学期已到期授权提交 | 权限按交易时点判断，不能按头像判断 |
| CF20 敏感数据 | 有权财务人员在授权范围读本人借款账 | 普通学生通过附件读取老师其他借款余额 | 保密范围与审核便利不能互相替代 |
| CF21 多问题并存 | 未批金额超余额、缺等效证据、会计仍未到账，各问题并列 | 只报一个OCR识别成功就给“通过” | 原因分层与可补行动单独列示 |
| CF22 申报撤回 | 未拨款前可依程序作废申请 | 已发放后直接删除原单宣告债务消失 | 需冲正或还款生效事件才能改账 |
| CF23 数字模拟 | 使用虚构校规写明借款上限和时限进行闭合基准 | 将此虚构规则当成都理工大学真正校规 | C/D分别保存模拟政策出处，保持适用性隔离 |
| CF24 付款部分批准 | 1笔借款中仅部分费用合规可冲账，余额保留 | 一行发票作废导致全部合法费用被一律拒绝 | 按费用行局部判断避免误杀 |

## 3. 自审追踪与对上游A成果一致性
