# G07-T07｜D阶段独立测试对接说明 v0.1

> 目的仅为让独立D测试作者理解业务入口、政策边界和可观察输出；不提供D的隐藏金标、不共享作者的“内部标准答案”、不干预D制作测试样例。

## 1. 单模板范围及稳定ID

- **唯一入口**：`G07-T07 项目借款与事后冲账结清预审`；一个借款生命周期贯穿多个操作。`借入/凭票冲账/银行归还/用途变更/延期/撤回/冲正`属于同一模板内部动作，而不是新增审核模板。
- **字段/材料/规则**：F-01—F-60、M-01—M-20、R-01—R-42（对应B的R01—R42）；内部条件BR-01—BR-18、等价证据EV-01—14、ST-01—10、ISS-01—17。
- **业务键**：`borrow_id`、`operation_id`、`expense_line_id`、`allocation_id`及正式`accounting_event_id`彼此独立；同一费用行跨多借款时需逐分配。
- **四类输入**：申报事项、申报材料、证明材料，以及单独标识的校内可信账簿/审批/银行记录。

## 2. 政策边界：D要独立明确试验规则

CDUT2022借款办法正式全文未得，2026新版线上具体借款角色/审批字段未得，校本通用清账期限与权限不得猜。D可基于完全虚构、内部自洽的明确规则独立造测；但不得把该数字写成真实CDUT校规。2025清单的“国内差旅借款金额**>50000元**须附经费负责人开支明细”只适用原时间范围；CL10互签只属于“实际借款人为经费负责人”的审批阶段；CL12暑期和CL13 2025年末属限定日期窗口。

## 3. 输出的可观察语义

应当至少包含：操作类型、分配行、是否超出受理范围、规则/政策版本、分项审核事实、缺件/冲突/系统待查、多问题与部分成功、拟抵借额、**已实际过账**抵借额、剩余债务、批准状态、执行状态、下一位有权处理人、材料证据页码/数据版本。**绝不能把“模型判断符合”当作“学校已批准/银行已付款/会计已销账”。**

## 4. 测试边界和证据来源

- 相邻费用合法性依据 G07-T01/T02/T04/T06 各自的正式审核记录，T07不擅自批准费用；出国审批依G05，采购验收依授权资产部门。
- 图像型原始合同/签字/收据应模拟为先栅格化再嵌入PDF；规则原始DOCX/网页/Excel可保留真实文本层。证据包**不得泄露审查者期待的问题或标准判定**。
- 未连真实学校预算/银行/税务接口时可使用标注为**虚构可信系统镜像**的账簿；否则正确行为是如实报告系统未核实，而不是猜已付款或绝对真伪。
- 隐私账号用虚构及脱敏Token，测试不可包含真实教师工资号、身份证或学生银行卡。

## 5. 与C作者自检的隔离

作者母版§15及《作者自检与问题修订记录》包含作者自己做的20条小规模流程推演。D**不能把它们当独立金标**，也不应让这些推演进入盲测用户输入。D应自主选择边界和生成材料，并将评测结论及失败案例在独立完成后反馈C。

## 6. C母版仍待独立评估的核心性质

本母版已表达三态触发、权限分离、跨费用行关联、部分冲账、外部台账、延期例外、政策版本和审批/执行不同步；真实编辑器与Agent端到端正确性**没有被本C阶段证明**。评测请同时覆盖正确合法通过与误杀，不仅是找错案件。
