# G07-T05_01｜办理情景与条件轴

> B2/B3研究产物；稳定编号 `Sxx` 为场景，不是D阶段测试金标；`Axx` 为条件轴，不是业务模板数量。所有具体高校金额由适用制度确定。[A01][A02][B01][B02][B03][B04][N01][N02]

## 1. 尽量小但能区分审核逻辑的条件轴

| 轴 | 取值/前提 | 与哪些轴可组合 | 审核规则影响 |
|---|---|---|---|
| A01 资金来源与制度 | 国自然基金/国家重点研发/四川省科技计划/其他纵向/横向/事业/合同外 | A02、A03、A04 | 劳务费范围、专家禁付、项目期限/预算、特定审批文件；国自然规则不能自动施加于全部横向项目 |
| A02 收款人类别 | 研究生或本科生助研；科研财务助理；临聘/访问学者/科研辅助；临聘独立专家；校内职工绩效 | 与A01、A03、A04、A06 | 必须**先选身份/资金类别**；在职员工工资/绩效需走另一个实质审批链 |
| A03 劳动/咨询事实形式 | 按工时、按日、按有效月、按任务成果、专家会场/现场/通讯 | A02、A04、A05 | 工作量表、考核、履约/意见证据、计算单位不同 |
| A04 发生与申请期间 | 本月、以前月份补发、未来月份预发、跨聘用期/项目期、休学/出境/毕业期间 | A01、A02、A03 | 是否能支付、停发与复学等按政策触发；不能简单“月份不同则违规” |
| A05 发放批次 | 1人1条、多人同类型、多人不同状态、同人多任务、多项目 | A02、A03、A04 | 逐行判定、可否拆分部分批准、反重复与历史台账 |
| A06 收款方式 | 本人银行卡、系统绑定卡已变更、原账户退汇、境外汇款、制度允许的委托代领 | A02、A04、A05 | 银行信息维护与代领条件、不得把其他学校外籍代领当作CDUT自动规则 |
| A07 审批权限 | 经办学生/导师/负责人，受益人也是负责人、学院/学工审批、已有有效签字或待办 | A02、A05 | 本人受款触发额外互签；系统已录入不等于审批完成 |
| A08 材料可信度 | 正式表单、电子审批、学生声明、工作量表、截图、银行R数据、系统不可达 | 所有轴 | 缺材料、无法联网、真实矛盾和附件尚未形成必须分开 |
| A09 工作渠道及规则版本 | CDUT旧纸质/2026智能，河海助研协议，东北农大按学期集中发放等 | 所有轴 | 先匹配学校+制度生效年+通道；不可把外校操作作为CDUT硬校规 |

**不做笛卡尔积**：如“外聘专家×导师电子助研聘用协议”“校内绩效×学生银行卡绑定”“未来月份×已银行成功”并非均是真实业务路径；无事实依据的组合不能硬生成一套场景。

## 3. 分支互斥与组合约束

- **最高优先级路由**：`funding_scheme`确定适用办法后，`recipient_type`确定申报类别，再由`work_type`确定证据槽。岗位定额助研/临聘工时/专家咨询/教师绩效互不当然等价。
- **相互不兼容的证据**：学生助研不提供专家职称证明；外聘专家不需要在校课程成绩单；申请科研劳务不需要零售发票；校外临聘协议不能被不相关的比赛奖状替代。
- **允许合法组合**：多人×多个本月/历史工作月；同批多位专家×不同咨询形式；学生在多个项目做不同任务；返款重付与银行卡变更。
- **需要人工/授权裁量**：项目任务真正是否完成、特殊超额发放、利益相关人员支出、外籍例外、部门互签、岗位绩效实质审定、银行转账真实性。
- **本次没有证明的普遍要求**：要求全部CDUT学生签“河海式电子协议”、对所有学校设每月200/700元、对全部临聘发放设“超5000元合同”、专家发放一律税前固定标准，均不可进入CDUT默认必需规则。

## 4. 生命周期与材料发生时序（用于避免错杀）

| 时间阶段 | 可合理已经存在的材料 | 此时不应要求的东西 | 状态改变 |
|---|---|---|---|
| 准备 | 项目与预算、用工需求/拟受聘人员、邀请意向 | 银行成功回执、未来月份工作量 | `draft` |
| 协议/邀请 | 已批准聘用协议、学生确认、专家邀请 | 专家尚未咨询的正式意见 | `contracted/pending_recipient_confirmation` |
| 劳动/咨询进行中 | 工作日志/阶段成果、签到 | 未到期月末全部工作成绩 | `work_in_progress` |
| 申请与初审 | 已发生工作记录、逐人发放明细、基础身份 | 财务审批完成/银行流水成功 | `submitted/needs_supplement` |
| 负责人及部门审批 | 签字/电子审批逐步形成 | 尚未完成的后续签批 | `waiting_approval/rejected/approved` |
| 财务与税务核算 | 审批结果、发放科目、税务计算 | 银行实际到账（未发送） | `accounting_ready` |
| 银行发放与归档 | 银行成功/退汇/重转记录 | 再次全额创建相同劳务事实的新单 | `paid/returned/reissued/archived` |
