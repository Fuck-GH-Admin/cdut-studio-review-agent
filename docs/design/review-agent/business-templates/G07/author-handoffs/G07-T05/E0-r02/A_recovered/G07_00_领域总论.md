## 0. 本轮任务和基线

**工作目的**：不把“都带发票/预算/项目号”当成同一审核模板，而是明确业务目标、申请主体、证据链、授权层次和输出结果，再进行目录筛选。A 阶段只做业务研究和分支交接，不产出正式审核模板、实测包或独立 Gold。

**真实输入基线（已读取）**：

- 旧《高校师生审批材料业务目录_v0.1.md》（本轮从用户文件 Library 查到）：G07-01竞赛/科研活动报销；G07-02学术会议差旅；G07-03活动物资支出；G07-04科研活动劳务或补贴。相邻 G05 对外出行、G06 成果/权属、G08 用印/公共事务；学生 S03 资助、S06 创新实践；教师 T02 人事、T03 科研、T04 财务、T07 公务等。

## 1. 校本优先的事实与版本风险

1. 成都理工大学财务处在2026年开账通知中要求原则上转用**智能报销系统**。2024年网页展示的“纸质预约—打印—投递”不能视作现行强制过程，仅保留当时业务材料及审核条件的证据作用。[CD01][CD15]
2. 学校2025年已发布新版**国内差旅费管理办法**索引，旧2016/2018年解释仅可用于历史业务路径，不能据此写入2026年强制补助标准。[CD04][CD05]
3. 本校2023年《采购验收管理办法》明确采购验收是付款依据，经过开箱、技术、综合验收等环节，权限归资产/使用等授权部门；验收报告不是财务模型可以自行签发的结论。[CD06]
4. 科研酬金指南将助研、专家、校外劳务和科研绩效区分上传材料；对“谁提交表单”“谁受益”“谁有权批准”必须建模为不同角色。[CD02]
5. 本校确有独立的借款制度及报账事项入口，但当前尚未取得2026版借款全文和新系统配置细节；只确认**有独立审核目的**。[CD10][CD13][CD14]
6. 学校2026年5月发布经费支出风险防范提示索引；真实性、相关性、合法性为跨业务共同内控要求，不是一套“统一报销万能模板”。[CD12]

## 2. 真正的 G07 业务对象图谱

| 业务对象 | 本质审核问题 | 请求的阶段性结果 | 例证 |
|---|---|---|---|
| 已发生的活动费用 | 活动、费用及凭证之间能否成立报销关系 | 项目费用可列支及可核销金额 | [EX01][CD11] |
| 已发生的差旅 | 人员、目的、行程及补助能否按差旅政策核销 | 分项差旅核销/部分核销 | [CD03][EX02] |
| 采购前需求 | 预算、采购授权、方式是否有效 | 是否准许进入采购执行 | [CD07][EX02] |
| 合同交付与付款 | 合同付款阶段是否具备相应条件；尾款须核验履约 | 付款材料预审（不是签发验收） | [CD06][CD08] |
| 人员酬金 | 特定人员、工作、月份、金额是否符合发放条件 | 批次人员与金额预审 | [CD02][EX04] |
| 主办会议/培训 | 是否先审批、实际参会、支出是否在预算内 | 主办会议/培训费核销 | [EX03][CD10] |
| 预借款与冲账 | 预支能否形成暂付款；事后能否结清 | 借款预审/冲账状态 | [CD10][EX11] |

**为什么与原四项不同**：原G07-03把事前采购、后端合同付款和技术验收混在一个标题里；这些动作的审批权限、时间性和提交证据完全不同。原G07-01的“活动费”也容易覆盖主办会议结算，需要分界。[CD06][EX03]

## 3. “师生共有”的发起权限真实含义

| 角色 | 典型行为 | 是否因此拥有最终审批权 |
|---|---|---|
| 学生（普通本科/研究生） | 竞赛垫付人、差旅参会人、材料上传人、助研收款人、委托经办人 | 否；具体能否独立发起须学校角色授权 |
| 学生团队负责人 | 准备活动预算、汇总参赛名单与缴费情况 | 不一定；导师/学院可能是费用责任人 |
| 教师、导师、科研项目负责人 | 项目经费申报、工作量/费用签认、预算承担 | 授权范围内可承担部分审核，不代表最终财务批准 |
| 学院/部门负责人 | 经费归口、活动与采购审批 | 只按权限边界审批 |
| 财务会计/资产/采购/人事/科研部门 | 会计核算、技术验收、采购方式、人事资格及实际付款 | 不同职能各有权限，不可由材料预审越权替代 |
| 受款人（学生/外部专家/供应商） | 收款与协议确认 | 不等于提出经费支出的合法主体 |

**重要边界**：学生被列为费用受益人，不足以证明他能申请全部校园采购。G07统一模板仅含条件化的学生入口；具体学校实际不得假定师生权力一致。[EX01][EX04][CD06]

## 4. 现阶段不宜被模型自动化替代的决定

- 发票在税务系统是否真实/已红冲、历史报销是否重复：需要权威税务/财务台账；只有截图时状态为“待系统查验”，不是通过或判伪。
- 技术验收报告是否能正式签署、政府采购程序是否合规、国外付款外事/税务审批：需要具有权限的岗位与记录。[CD06][CD07][CD08]
- 助研发放资格、导师考核或专家绩效的主观评价：规则可抽客观字段，最终人事/项目管理审批需人工有权主体。[CD02][EX04]
- 正式账户支付：材料齐全只是**提交有权审核/可补材料**，不是资金已经出账。
