## 2. A12：2024年学校科研经费正式办法的可直接复用结论

### 2.1 项目性质决定支出约束（第1、2、3条）

- **第1条**：科研项目负责人须签《成都理工大学科研工作者承诺书》，对科研经费合法性、合规性、合理性、真实性、相关性承担直接责任。该承诺不代替财务及学院的审批。**建模为项目责任证据/底账**，不对每名受款人强制上传一份承诺书。
- **第2条**：预算制纵向项目**非设备费**的费用调剂权下放项目负责人；不能因为某一细化预算栏目数额与申请不符就直接推定违规，需依据有效预算调剂权限和校财务记录判断。
- **第3条**：横向科研项目经费除管理费、税费外，采用在开支范围内据实列支的“包干制”思路；劳务费、专家咨询费、技术成本补偿费均可能在允许范围内。技术成本补偿费比例上限在不同学科情形下不同（40%与60%），**这些比例属于技术成本补偿费，而不是研究生助研或专家咨询费统一比例上限**。

### 2.2 绩效材料与审批层级（第4条第3项）

对于纵向科研项目绩效，文中有明确的**负责人提出业务考核申请 → 学院考核 → 负责人制定绩效分配方案 → 学院审批 → 发放**过程。这实证支持当前B阶段将“教师绩效的实体分配审核”与“T05酬金财务发放预审”分开：T05可以读取**学院已批准的考核和分配结果**，但不能自己替学院决定绩效水平。旧2024酬金指南所列《科研绩效考核报告》《绩效分配方案》并非只有名称而没有责任链。

### 2.3 专家咨询费的学校一般审批路径（第9条第2项）

本条明确：专家咨询费执行适用国家标准，申请报销时提供**由专家签字确认的专家咨询费发放表**，项目负责人审核签字后发放，**取消科研管理部门的审核环节**。这是相较B阶段v0.1的**重要校本原始制度补证**。

**限定**：文件未在这一条规定所有项目类别统一金额，更没有排除资金主管部门或内部特殊用途项目所需的其他审批；具体须匹配资金方案、部门专项规定及后续有效文件。不要把“取消科研管理部门审核”理解为**取消所有学院、领导、财务或本人受益互签**。

## 3. A13：科发院专家咨询/评审费专项——能建立高质量条件分支的完整实例

### 3.1 条款所限的经费范围（第3条）

仅对**科发院项目号 `80303-FZ11200`**的科技管理活动支出：科研项目/平台/奖励/人才/资质的培育、推荐、验收等，并含校内外专家。因此：

- `funding_source=80303-FZ11200 && purpose=科发院相关管理活动 && expert_consultation_or_review=true` 才能考虑采用以下专属标准；
- 对普通横向科研合同、国家自然科学基金、一般研究生助研或任课教师课程评审，不得据此无条件套用本表。

### 3.2 发放标准及金额计算（第4、5条，**税后**）

| 专家档次 | 每人完整工作日税后控制标准 |
|---|---:|
| 院士 | 3600 元/天 |
| 正高级职称专家或评审组长 | 1200 元/天 |
| 副高级职称 | 1000 元/天 |
| 其他专业人员 | 800 元/天 |

**条件**：艰苦边远地区评审上浮10%；会议形式**半天按日标准60%**，连续工作**第3天起**按日标准50%计、**第8天起**按日标准30%计；通讯形式按**每次日标准的50%**。标准不包含专家食宿和城市间交通，如需承担费用另依相关差旅规范。以上涉及税后基准和个人所得税代扣，不能将1200元税后标准直接等于项目成本1200元。

**示范计算——仅用于理解该专项的条件逻辑，不是D阶段金标案例**：一名正高级专家以会议形式连续工作3个完整工作日，按该办法控制的税后金额为 `1200 + 1200 + 1200×50% = 3000元`，未含经规则允许的交通食宿。真实资金的税额和最终付款金额仍由财务系统处理。

### 3.3 不得领取者及审批证据（第6—10条）

- **禁止领取**：组织评审的本单位工作人员、因履行岗位职责参与评审的管理人员、因岗位职责参与评审的学校专项工作领导小组与各委员会成员。需要用**当次组织者/岗位职责/受邀专家身份**判断；不能见到“校内教师”四字就不加区分地判全部不合格。
- **事前审批**：牵头业务科室在评审前填写《科学技术发展研究院、地质调查研究院经费使用审批表》，获批后执行。这是`A13`**专项条件**，与A12一般科研项目的签批材料不能互相覆盖。
- **发放凭证**：专家个人签收信息/发放表、姓名、身份核验字段、发放金额、上卡银行及账户；应依法依规代扣税后支付个人。不能把发放后产生的**银行成功回执**设为初审阶段必交。
- **同一项目评审或咨询只能报销一次**，按专家实际工作时间计算，不得向其他工作人员借名发放；**同一领域的不同独立评审事项**是否属于“同一项目”需项目号、评审轮次及任务关联证据，不能仅按姓名和同一天直接判重。

### 3.4 A12与A13并不是相互矛盾的“一般规则”

- A12的学校层级一般科研咨询费审批强调**专家确认+项目负责人签字**、简化科研主管部门审核；
- A13是在**科发院特殊项目和活动**里增加“牵头科室**事前经费使用审批**+专家签到/发放材料+税后专属金额+禁止领取角色”的专项要求。应使用`fund_type/purpose/approval_stage`条件路由；**不能把一个项目的政策拿去覆盖另一个项目，也不能简单取交集制造额外审批**。
- 研究材料中对“专家咨询费发放审批表”与“专家签收表”要区分**审批和执行阶段**、不把它们视为一份文件即可互相替代。

## 4. A14：国家重点研发/重大专项项目的资金用途与人员约束

该正式办法由学校2025-10-06印发，只对明确的国家重点研发计划/国家科技重大专项对应项目、课题、专题有效：

- **第5条第4项、第12、13条**：项目负责人是资金直接责任人；劳务预算应据实编制，财政来源与其他资金要分开核算；预算与合同/任务书是本类别经费是否可发放的可信依据。
- **第14条**：劳务费、专家咨询费等原则上走**银行转账结算**；不应按旧版“银行卡或现金一张单不能混填”就理解为2026仍普遍允许现金发放，尤其本类项目有更具体的银行优先规则。
- **第15条**：不得编造虚假劳务合同、虚构人员名单虚报冒领劳务费和专家咨询费；不得列支个人不相关开销。这能支持**核查真实工作和受款人**，但模型不能仅靠OCR看起来奇怪就自行断言已构成违法犯罪。
- **第16条**：项目/课题配相对固定科研财务助理，其角色是**协助项目财务管理**，并不因此获得代项目负责人签批或自行领取未经批准薪酬的权力。
- **第9条**：涉密项目要在专门的涉密管理流程中开展，不能将密级内容引入普通G07-T05公开审核材料包或上传到未经授权的普通服务。这应当触发**移交合规受控流程**，而非尝试识别秘密项目内容。

**重要新建模字段**：`funding_program_type`、`project_task_level`（项目/课题/专题）、`budget_source_type`、`project_principal_from_taskbook`、`classified_project_flag`、`bank_transfer_required_by_fund`、`amount_approval_chain`。

## 5. A15/A16：真实的科研助理“聘用”与“助研酬金发放”不能混淆

2026-06-13学校层面科研助理招聘公告明确：研究助理岗位是**社会用工、编外合同聘用**，面向2026应届毕业生招聘，需完成资格审查、面试、公示、体检及正式入职。数学学院、实验室还有各自项目招聘公告，说明有院级/项目岗位和校级聘用两条现实路径。学校层面公告的聘期是2026-09-01至2027-08-31。[A15][A16]

- **能直接证明**：存在真实的“高校毕业生科研助理聘用”这一**人事/项目用工业务**；聘用合同和有效期间是后续支付核验所需的上游事实。
- **不能证明**：这些聘用岗位的具体工资属于G07-T05学生助研津贴；也不能以“必须2026应届毕业”拒绝仍在读研究生申领导师按项目发放的助研劳务费。
- **模板边界**：招聘录用与用工合同订立去教师人员聘用/人事岗位业务；本模板负责读取已经有效的聘用/工作/预算/发放证据。敏感的招聘政审/心理测评/体检内容**不应作为普通酬金审核系统默认收集字段**。

## 7. 本次补查的审计结论

1. **没有证据要求将G07-T05拆成更多独立模板**。专家身份/资金来源/计费方式/工作期间仍属于统一“个人科研酬金发放预审”目的的条件分支，实际“专家咨询 vs 助研”证据和金额模型则严格隔离。
2. **明确禁止将A13标准错误扩张为“成都理工大学所有专家咨询费统一标准”**。若审核依据中未指明资金类别及适用制度，应标注`policy_scope_unresolved`并走补充配置/人工核实，而非随便择最严数额。
3. **A12与A14补齐了项目资金与责任链的权威来源**，可以在C阶段明确哪些是客观可核的签字、任务书、发放计划、工作记录，哪些仍需人工或后台核验。
4. **没有取得2026智能酬金模块完整界面、全部银行/税务接口、一般助研月额、全部历史附件DOCX原件**。它们是部署校本配置缺口，不应以“查不到”误判申请人不合格。
5. **阶段结论仍是 `READY_WITH_CONFIG_GAPS`**。可以继续 C 阶段的条件化模板编写，以及 D 阶段在完整规则/来源隔离条件下的独立盲测设计；不需要为未知字段无意义地无限延长B阶段。
