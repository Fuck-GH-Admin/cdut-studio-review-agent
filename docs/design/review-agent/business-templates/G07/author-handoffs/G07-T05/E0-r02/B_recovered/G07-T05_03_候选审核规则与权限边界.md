# G07-T05_03｜候选审核规则、证据层级与权限边界

> B5 研究稿。每行是**规则事实与判定研究**，不是C阶段最终规则JSON。分类：`CDUT`已验证校内对应材料/流程；`N`指定资金上位规则；`X`跨校官方方案提示；`DESIGN`用于系统安全的校验建议。仅以适用版本、主体、资金来源为前提。

## 0. 权责分类

| 能力 | 系统可以做 | 不可直接做 |
|---|---|---|
| 确定申请要素 | OCR/结构化提取项目号、人员、工作期间、金额、工作事实；关联证据 | 仅依据学生/教师自述确认预算余额、身份、项目金额已经批准 |
| 资格审查 | 对已授权学籍/项目/人事数据进行规则比对，附证据来源 | 未经授权查询其他人的工资/卡号/税务档案 |
| 咨询是否真实 | 识别邀请函、咨询记录、实际成果之间逻辑冲突 | 自行认定专家观点学术上正确并替代有权审批 |
| 净额与税务 | 可校验已有系统税务计算是否有字段缺失 | 用一个税率在不了解完整个人税务情况时自行确定实际应缴税 |
| 申请审查状态 | 材料受理/待补/待审/风险送人/已由权责部门批准等事实 | 预审“通过”后直接改为财务会计已付、银行卡已到账 |

## 4. 五种关键金额语义（不是一套“劳务费公式”）

1. **研究生协议月额**：按真实受聘协议规定的月标准×已发生的有效月数，不能提前发尚未发生工作；可否按天折算由该校制度和协议约定决定。[B01]
2. **临时按工时劳务**：`认可工时 × 合同或有效批准的计时单价`；必须确认工时合法、单位、任务和经费预算。[B04]
3. **按成果劳务**：合同/任务确认的实际工作成果对应约定报酬；不能擅自用“工时×模型猜单价”替代有效协议。[B04]
4. **专家咨询费**：按适用项目资金的职级、会议/现场/通讯方式、半天/全天/第三天以后不同系数，并明确税后/税前。中央财政财科教〔2017〕128号规定税后范围，且中央项目专家不能是项目研究管理人员；具体以该规则适用为前提。[N02]
5. **教师科研绩效**：间接费用激励与薪酬审批范畴，按人事科研预算分配制度，不等于“按助研工作量开学生劳务”。[A02][N01]

研究建议以整数分存金额，记录 `gross_amount` / `applicable_rate_basis` / `tax_withheld` / `net_disbursed` / `budget_approved_limit` / `historical_paid`；税务要由有权限的实际制度引擎处理。

## 5. 审核输出与权责分工建议

| 本轮预审动作 | 确定意义 | 不能扩大为 |
|---|---|---|
| `in_scope` | 该申请目的属于科研人员酬金发放 | 人员一定合格 |
| `documents_complete_for_stage` | 当前阶段的触发材料齐全 | 负责机关已经审批 |
| `needs_supplement` | 本业务当前阶段确定必交材料欠缺，无可信替代 | 全部事项正式驳回 |
| `external_verification_pending` | 学籍/预算/身份/付款历史接口不可达 | 客观事实为假 |
| `requires_authorized_review` | 身份/利益冲突/规则裁量/签批环节待权责人员 | AI自行审批同意 |
| `referred_to_other_workflow` | 教工绩效/事业劳务/勤工助学已超出本模板 | 申请人失去本应享有的业务申请权 |
| `approved_by_authority` | 已读取有权部门正式批准记录（不是AI自己的动作） | 资金已在银行成功到账 |
| `bank_paid` | 银行或财务已提供实际支付成功可信回执 | 学校还能免除后续追缴/冲销流程 |

## 6. 四类不能把上游资料混同的高风险判断

- **资格条件冲突**：青海师大“有工资性收入教工通常不得直接领取科研劳务”不等于国自然所有校内职工工资性收入都不可通过间接绩效支付；要看不同的收入科目、法定制度和岗位审批。[B04][N01]
- **现行资料冲突**：2024CDUT让学生助研交自制工作量表，2026平台可能可直接导入系统工作日志；不能仅因没有纸质PDF就断言不合格。[A02][A03]
- **历史金额冲突**：中央财政专家税后额度≠西工大税前额度≠东北农大助研定额；三类数值不得跨校比高低择严。[B02][B03][N02]
- **负责人自我审批**：CDUT最新须部门领导互签。这个额外签批是确证的高价值校本规则，但若处在`刚提交`阶段仍不可要求最终签名已生成。[A04]
