## 4. 校规差异与原A阶段需要的修正

| 冲突/差异 | 应保留的处理结论 |
|---|---|
| 2024“酬金预约打印投递” vs 2026智能报销 | 业务附件证据可参考，执行技术步骤必须转向2026新平台，具体提交格式为待配置[A02][A03] |
| 2024科研绩效也列酬金菜单 vs A阶段将其放教师边界 | **不忽略校本事实**，允许T05识别其业务并校验既有正式分配材料，但分配合理性/收入性质送T02/T03；本模板不单独作教师岗位绩效最终判定[A02] |
| 2024横向结余绩效“无附件” vs 纵向绩效“必传” | 仅历史渠道上传要求差异，不代表横向薪酬免实质政策审查[A02] |
| 2025现金/银行卡两种单分开 vs 2026学生银行卡维护 | 银行维护路径确认；现金发放现行是否允许仍待配置，不能全部一律判违规[A01][A05] |
| 河海协议与东北农大定额 | 同属助研，但前者有个人协议签订/确认、后者有学校定额批量发放；都是条件流程，不应强制合并附件[B01][B02] |
| 财政部专家费税后 vs 西北工大专家费税前 | 必须记录`rate_tax_basis`及资金适用范围，不使用跨校统一公式[N02][B03] |
| 一般不能给校内职工发直接劳务 vs N01研究人员范畴 | 不把“校内职工”一概视为绝对不得取得所有科研项目工资性补助，应看直接劳务/间接绩效/合同服务类型[N01][B04] |
