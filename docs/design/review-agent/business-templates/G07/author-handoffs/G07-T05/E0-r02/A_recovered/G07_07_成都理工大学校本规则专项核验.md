> 核验日期：2026-10-12  
> 对象：G07-T01 至 G07-T07，共七套候选模板。  
> 性质：公开校本证据检索与核验记录；不是学校授权的现行审批规范，也不是正式审核模板。  
> 与 `G07_A阶段_领域总调研_v0.1` 配套使用；如本补充与 v0.1 的“未获取”描述冲突，以本次证据可得性为准。**本轮到此结束，不进入 B 阶段。**

## 0. 结论（先看）

**结论：能够找到成都理工大学针对七套候选业务的大量校本公开依据，足以开始 B 阶段。** 但“找到业务清单或历史操作指南”不等于“完整掌握 2026 年最新制度全部条款”。

- **直接阅读到学校原文/PDF**：2025年4月财务“只跑一次”事项清单（17页）、2023年《采购验收管理办法》（10页）。其内容覆盖直接费用、差旅、材料设备、酬金、会议培训与借款冲销。
- **官方网页完整内容已检索取得，但直接打开有时返回 HTTP 412**：2026年度开账通知、2024年各财务标准流程、2025年采购计划通知、2026年采购推进通知、校内风险提示等。可确认具体披露内容，但标记为“官方检索可读，直开受限”，不能谎称已完整下载所有原始附件。
- **只有学校网站目录或摘要、制度附件全文尚未逐条核验**：2025年《国内差旅费管理办法》（成理校发〔2025〕33号）、2022年《借款管理办法》（成理校发〔2022〕39号）、《非政府采购实施细则》全文及2026年新增的验收材料说明。不能据此提前硬编码所有金额门槛、签批人或冲账期限。
- **流程版本有变化**：2026-01-13学校通知明确从2026年开账起原则上不用原网上预约报销系统，改由智能报销系统办理。2024/2025清单中的“预约单打印、纸质投递”不是全部业务的2026现行必经步骤。

**总判断：`DOMAIN_READY_FOR_BRANCHING`（延续）。** 校本资料的未知部分进各模板的 `school_rule_config_pending` 或“需授权系统核验”清单，不能让被审材料因此自动不合格。

### 1.1 T01：日常、活动、竞赛、科研直接费用（与采购分界）

学校《“只跑一次”财务事项清单》（2025年4月，第3页/第10-12页附近）及2024年事业经费流程公开了：

- 学生活动费：相关票据、《学生活动经费使用明细表》或包含活动时间、主题和人数的事项说明。
- 办公印刷费：相关票据；**发票不含商品明细、且单张发票超过500元**等情形出现供货商盖章商品清单要求；发票已完整列明细时有替代路径。
- 科研版面费：国内外不同，须能够证明对应文章；国际汇率、外汇税务等属于条件材料。
- 科研专利费：随支出类型核对专利受理/证书、预算任务书/科研合同及相应票据。

**注意**：T01 不要把合同采购的付款、科研出差、举办会议费用或向个人发放报酬混入同一审核对象。清单可以用于 B 阶段提取材料字段，**但 2024 流程中的“打印预约单再投递”应被2026新流程校正**。

### 1.2 T02：国内非科研差旅 / 科研差旅 / 学生学术交流差旅

2025财务清单及2024官方流程确认：

- 非科研出差：票据、出差事前审批、参加会议时的会议/培训通知；特殊情况审批单、遗失票据审批单按条件提交。
- 科研出差：交通/住宿/保险/退改签票据、科研出差审批单、会议通知；**租房、由对方提供住宿、票据无法取得**等情况有各自替代佐证路径，不宜全部直接拒件。
- 2025年校财务处网站另列《国内差旅费管理办法》（成理校发〔2025〕33号）及科研差旅标准、地区住宿标准。官方常用信息可见非科研公杂费**省内50元/人·天、省外80元/人·天**，科研差旅标准单列。**暂不将该两数视为所有学生/所有科研人员的通用标准**，需核全文的适用对象与特殊情况。
- 旧《国内差旅费管理办法》（2018版或2024流程中提到的文件）不能覆盖2025同名新制度的条款。

### 1.3 T03：采购事前合规预审

2025年5月采购中心通知要求单位明确负责人、经办人；确认采购项目、分包和采购方式；推进市场调查与需求论证，填报需求论证表及采购意向公告。2026年3月学校采购推进通知再次要求已备案项目加快需求论证和采购意向申报；对自主采购按学校现行实施细则操作。

**证明链**：采购计划/资金来源 → 采购品目与项目需求 → 论证与调查 → 采购方式 → 所需的审批授权。

**不能预判**：某高校的三家供应商/1万元合同阈值等，直接套为本校全部2026项目的规则。2023年采购补充说明存在历史要求，但最新细则与适用时间还需核验。

### 1.4 T04：采购交付验收与结算

2023《采购验收管理办法》（10页、已读原始PDF）直接支持：

- 管理中心实施的货物采购为主要适用对象；**单位自购物品、图书期刊、工程**均有不同责任路径，不能统一按同一货物验收单驳回。
- 货物验收涉及开箱、技术、综合验收；综合验收小组的组成及单价10万元、同类同型号批量50万元分档属于**该验收组织规则**，不是采购立项的金额阈值。
- 验收合格与支付具有关联；第4条写明未经或验收不合格项目不得支付采购资金。**具体付款阶段如合同约定依法允许预付款时，必须结合付款性质及最新有效规则独立分析，不可把最终验收规则机械套到所有预付款。**
- 所附真实表单：服务合同验收表、货物开箱及技术验收表、货物验收工作方案、货物综合验收表。可直接用于 B 阶段字段分析。
- 国资处2026年3月出现《关于验收结论材料的说明》目录条目，**尚未取得可用全文**。

### 1.5 T05：科研酬金

2024年科研经费“酬金发放标准流程”中明确分支：

| 子类 | 官网明确的典型附件 |
|---|---|
| 助研津贴 | 《工作量统计表》，项目负责人审签 |
| 科研财务助理劳务 | 五方协议 |
| 校外人员科研劳务 | 工作量统计表；人员信息先维护 |
| 科研技术成本费 | 新项目A/BH编码、旧项目如SH存在不同附件规则 |
| 纵向科研绩效 | 《科研绩效考核报告》《绩效分配方案》 |
| 横向结余科研绩效 | 旧流程说明无需额外附件（应核当前政策） |
| 专家咨询费 | 《专家咨询费发放审批表》 |

必须区别：**学生是否领取助研津贴**，与**谁能审批并发放项目酬金**是不同角色；教师绩效等也不应误入学生助研审核。

### 1.6 T06：主办会议及培训

2025年财务事项清单与2024办事流程明确：

- 非科研会议：会议通知、实际参会人员说明、费用明细及相关票据。
- 科研会议：校内举办会议的人员情况说明和相关批准；校外酒店举办涉及会议通知、签到、费用结算及酒店方相关证件，在旧清单中会议费用超过2万元的情形要求合同。
- 培训：举办培训需通知、参训人员说明；参加线上培训则按对应情形提供通知，不应要求不存在的住宿签到材料。
- 出席别人主办的会议而产生的个人差旅，不在T06审核，应归T02。

**上述条件的“2026是否调整”仍需校财务处现行标准及实际上传路径确认。**

### 1.7 T07：借款、还款和冲销

2025财务清单《现金退还款》章节直接展示智能报销的还款方式：向学校账户汇款、保留汇款凭证，再在系统选择现金还款和冲销借款。2024年科研借款流程显示不同借款用途对应不同事前附件（差旅审批、实习事前审批、版面费相关资料等）。

2022年《借款管理办法》已被财务处2025-11学校规章目录列示，但未核验条文和借款责任主体。2017年“往年借款清理”通知只作历史风险与异常处置证据；其逐级签字要求不得作为2026日常冲账的固定流程。

## 2. 2026 流程变更，需覆盖所有七套模板

1. **系统替换**：2026-01-13《2026年度财务开账通知》明确：2026年开账起，原则上不再使用旧网上预约报销系统，各单位改用智能报销；包括票据上传、线上审批、委托单/非委托单判断等路径可参考财务公开操作资料。
2. **证据仍需分类型**：新系统不代表纸质合同、验收原件、报销票据全部无须留档。2025清单说明电子票据、其他纸质附件与“委托/非委托单”的不同操作，但不能据此断言2026每个细节完全不变。
3. **事前/事后分别判定**：T03事前不强行索取采购完成后的发票、验收单；T04结算时不重新授予采购权限；T07借款审批不代表放款已发生。
4. **双重来源判定**：OCR解析结果不足证明票据真伪和“历史未报销”事实，需从财务台账、有效审批记录和税务/发票系统核验。接口不可得时列明“无法自动核验”。
