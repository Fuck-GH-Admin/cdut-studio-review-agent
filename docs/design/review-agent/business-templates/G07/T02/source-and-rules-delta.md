## 1. 针对的问题与实证边界

**缺口不是“城市无住宿发票即可报销”。** 原 v0.1 `MS-06` 已允许“住宿无合法票据”提交情况说明，但 `EV-07/R-17` 唯一明确的无票等价证据路由为“科研艰苦野外”，`MS-16` 又将住宿发票作为申请房费的通常材料。城市科研出差**已实际支付房费但客观无法拿到住宿发票**的受理/人审路径缺乏明确串接；自动拒整案与自动允许无票房费都没有证据支持。

**源事实区分：** F1与F2/F3不是同等层级的“扩大授权”；F1只是较宽的材料清单表述。2026城市科研有偿住宿无票是否可核住宿费，属于 `SOURCE_PENDING`，须由有权财务/制度管理方确认。**封闭模拟政策 S：本轮未制定，也未以外校规则代替校本门槛。**

## 2. 全路径静态遍历

| 对象 | 旧版 v0.1 行为 | 本轮所见与改动范围 |
| --- | --- | --- |
| BR-07 | 区分零房费、已付有/无票、野外、租房等，但城市无票的下一步未明确 | **新增同一轴的 BR-07-U 子条件**（不建新模板、无新全局轴），将城市科研“有实际付款、客观无法取票”转入人审询源 |
| MS-06 | 泛指无住宿费/租房说明 | 受理城市案例的**说明与真实付款/住宿事实**，但只是材料提交入口 |
| MS-16 / EV-05 | 住宿费通常凭真实发票、酒店明细 | 保留常规有票组；未取得发票时不将“订单或付款”直接等价为税票；城市状态为待核 |
| EV-06 / R-15 | 他方**免费**提供住宿 | 城市自己已付款，不得误走“免费包宿、房费为零” |
| EV-07 / R-17 | 仅科研艰苦野外缺票例外 | **保留限定适用范围**；不得靠 `field-trip` 标签外推城市，也不能把有签名说明写成已核销 |
| EV-08 / R-16 | 租房合同/税票/收据/付款匹配 | 普通城市酒店已付不属于租房，不以房东身份证/租房协议强制挡路 |
| R-14 | 有发票但发票明细不足→补酒店清单 | “发票根本不存在”≠“已开发票但缺房晚字段”；城市缺票转BR-07-U |
| R-18 | 交通票据遗失 | 不替代住宿发票，不能跨费用类型套用 |
| R-34 | 缺材料/未到阶段/政策未知分流 | **明确城市无票→政策适用未定、人工核源；房费`AMOUNT_PENDING`** |
| R-35 | 逐费用行输出 | 保留交通票据可独立核验，不因房费来源未知整单拒绝；不代表财务已付款 |

| **A 城市科研已付无票** | 已完成获批的科研外出、城区酒店实际住宿与支付、客观不能取票、MS-06说明（可有签认），非野外，交通票据有效 | EV-05不完整，EV-06/07/08均不适用；BR-07-U→MS-06→R-34；R-14不负责“无票” | 住宿费准报依据`SOURCE_PENDING`，须`HUMAN_REVIEW`，金额`AMOUNT_PENDING`；车票等行独立继续。说明签批不是银行支付事件。 |
