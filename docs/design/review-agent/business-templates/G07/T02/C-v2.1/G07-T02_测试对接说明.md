## 3. 预审结果和合法例外

- 费用行优先、整案次之；补件、不可核、来源冲突、权威系统断连要单独编码，不用一键驳回全部。
- 真正有权审批记录和银行支付回执是分离事实；全量可读的扫描PDF也不证明税务票据真实。
- 条件为未知不能默默当假；尚未发生的旅后票据`NOT_DUE`；没有住宿费用时“酒店发票必交”条件不触发。
- 差旅标准与学生档次为校本/资金政策配置；封闭测试若要得到唯一数值必须提供**有效、自洽、完整的模拟学校规则**。
- D独立评测可检验错批与误杀、过度索要附件、金额误差与追溯是否准确，但不应将C作者走查当金标。

## 4. 输出契约与追溯

每笔业务至少输出：`claim_id, trip_id, traveler_id, line_id, cost_kind, policy_version_or_unknown, rule_ids, decision_state, amount_or_null, evidence_refs, next_actor_role, issue_codes, authority_state, payment_state`。同房共票等关系用稳定对象键，避免几笔费用串案。

学校当前学籍/人事/预算/发票税务/财务历史和OA/外事接口没有在C阶段得到授权，也未进行真实校本端到端测试。正式数字必须基于现行条款及有权数据，不能用C模板中的CDUT部分网页数字猜测。
