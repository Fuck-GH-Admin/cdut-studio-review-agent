# G02-T02｜受限 Gold 私有隔离管理员清单

**当前：`private_acl_storage_configured=false`、`ACL_UNVERIFIED`，没有配置过，也没有通过实际权限测试。**

### 外部受限存储要求

- 建议独立的组织授权对象存储容器/私有库，而不是公开GitHub、公开PR、普通CI artifact或公开分享链接。
- 私有路径由存储管理员写入**私有工单**，公开台账只能登记存储记录编号，不能公布Gold对象URI、密钥或具体个人账户。
- 对象名 `G02-T02_EVALUATION_ONLY.zip`；原始SHA-256：`9ba244eb1b884f7da4d8762d44a4b7bc168fde9d34fa3a58821625391d804b7a`。
- 上传必须保留原ZIP字节和版本号、启用服务端加密、默认拒绝、禁止匿名及跨组织公开访问、访问/策略修改审计日志，并建立紧急吊销机制。
- 最小许可主体：经指派的D资产保管管理员写入/封存；**已冻结E1事实且经批准**的E2验收账号按工单限时只读；C作者、未冻结E1审查者、公开CI、普通开发者、测试输入持有人及匿名访问者一律无读权限。
- 原D作者不因持有原文件而自动获持久读权；E1人员与E2开放阶段做隔离。

### 验证门槛（管理员真实执行后填写证据ID）

- [ ] 确认存储负责人、工单ID、合规的受限存储位置及对象版本号。
- [ ] 从私有对象**重新下载**并复算SHA-256同值。
- [ ] 匿名请求、公共CI凭据、C作者、未冻结E1审查者实际访问**全部失败**。
- [ ] E2受控白名单用户在授权时间窗口内可以读取；权限超过期限后失效。
- [ ] 上级组继承、分享链接、对象/桶策略、服务端加密、审计日志及应急撤权得到记录。
- [ ] 存储管理员及E r02验收人员分别签署实施/复验日期。
