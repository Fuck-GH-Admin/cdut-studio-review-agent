# G04｜单变量中性反例与反向解释（辅助研究；非首次独立 E1）

**BLINDING_COMPROMISED**：本会话已在收到子会话提示词前接触旧 C/E 语义对照。以下案例虽从官方原文推演，但不是合格的初次盲审案例源锁；不得据此自动开启正式 E2，禁止称发现 C/D 具体错误。本文件不含历史 Gold、评分答案、校内真实个人信息。

## 方法

一个“最小反例对”必须让所有其他可影响结论的事实 **显式相同**，仅改变 1 个事实；输出仅是材料预审可建议的法律/业务状态，不是学校、公安或消防机构的正式批准。F 仅基于适用法条，U 不可变成强制拒件，S 本轮 0 条。对未知适用条件作“假定它已满足”的对照，只用于证明逻辑分支，不能声称真实校本条件已满足。

### F-PAIR-01｜面向公众表演：999 人与 1000 人

- dutyId: F-G04-SRC-06/F-G04-SRC-07。
- sourceLocator: 国务院令505号第2、11–13条；https://xzfg.moj.gov.cn/front/law/detail?LawID=204&Query=
- applicability: 某依法成立的社会组织，在成都理工大学校内非日常营业演出场所举办面向**社会公众**的文艺演出；非505号令所列法定例外；以单场为单位。**该对照只评估505公安许可门槛，不裁定28号令第15条中“校园大型”的未定校内分类。**
- changedFact: A = 该场预计 **999人**；B = 该场预计 **1000人**。组织主体、演出类别、公众开放、地点、非日常营业场所、其他安全事实完全不变。
- expectedDecision: A = 单场人数要件未满足，不能仅按505号令要求该活动的公安大型群众性活动安全许可；B = 符合该人数要件，且其他既定必要条件满足时进入公安安全许可流程，需要法定申请材料并由有权公安机关审定。两种情形均不等于已可举办。
- admissibleAlternatives: 原始注册人数与承办计划等证据冲突 => SCOPE_UNKNOWN/PENDING_AUTHORITY，而非假设一方属实；活动实质类别/例外发生变化需重新判定。
- evidenceAnchors: 单场预计参加人数，活动类型，受众公开方式，主承办者身份，场所日常经营属性，场次ID，法律版本。
- failureMode: 只看累计人数而不看单场/公众性/活动类型，或把达1000人误作公安已许可。
- confidence: 高（人数边界适用范围），校内现场消防条件保留 U。
- unresolved: 校内“大型活动”消防分类和必要申报执行细则，均未由该对照解决。
- reverseInterpretation: 影剧院等在日常业务范围内举办活动、直接由政府部门举办或属于其他专门行政法规的演出，可能不走相同505普通许可路径；此时应另验，不能只用数字判定。

### F-PAIR-02｜相同 1200 人演出：公开社会公众与仅特定邀请

- dutyId: F-G04-SRC-02/F-G04-SRC-06。
- sourceLocator: 国务院令505号第2条 + 教育部、公安部令28号第15条；https://www.moe.gov.cn/jyb_xxgk/xxgk/zhengce/guizhang/202112/t20211206_585092.html
- applicability: 同一在校内举办的1200人文艺演出，同一组织、同一日期场地、同一公众安全方案及非日常营业场所，假定其被校方按第28号令定义为大型活动。对该“校内大型”假定仅用于本对照，不产生CDUT的1000人内部门槛。
- changedFact: A = 向社会公众开放报名；B = 仅明确限定名单的校内成员和特定获邀人员可参加，**不向社会公众开放**。其余全部不变。
- expectedDecision: A = 505号令公众要件可成立，须连同其他要件判断公安许可；B = 505号令“面向社会公众”要件未满足，不能仅凭人数强制公安许可及20日前申报。**两边在已假定其属于28号令第15条范围的条件下，均不消除学校消防现场检查要求。**
- admissibleAlternatives: 若所谓“邀请名单”实际人人可获得，开放性质存在冲突 => 人工核定；若并非校内大型活动，第28号令第15条适用前提还须另判。
- evidenceAnchors: 报名链接可见性、活动邀请规则与核验记录、举办单位、单场人数、法定活动类型、校内消防现场检查记录。
- failureMode: 505审批与校内消防检查混为一项，或把“邀请校外专家”等同“面向社会公众”。
- confidence: 高（28/505法条在其各自适用前提成立时）；本校“校内大型”界定 U。
- unresolved: 成都理工大学2026年实际校内活动申请表和授权岗位。
- reverseInterpretation: “不面向社会公众”不意味着无其他法定义务；反之，校内受众规模很大也不必然进入505公安许可。

### F-PAIR-03｜同一校内大型活动：消防现场检查未完成与已合格

- dutyId: F-G04-SRC-02。
- sourceLocator: 第28号令第15条；教育部发布机关原始正文同上。
- applicability: 依法应受学校消防机构现场检查的校内大型活动，主办和具体场地、设施、消防措施、疏散预案及应组织的演练均已按本条落实；假定一切其他必要外部许可（如果有）已依法完成。
- changedFact: A = 由学校消防机构实施的活动现场检查 **尚未完成**；B = 该场次该地点的现场检查 **已经合格，且有权记录可核**。其他事项及当前拟举办日期不变。
- expectedDecision: A = 活动不能被系统预审直接声称满足法定举办前置条件，应标记待学校消防现场检查，不能无记录代出正式结论；B = **只满足这一个消防检查前置义务**，不得从该记录推导公安许可、场地许可或其他全部条件自动通过。
- admissibleAlternatives: 存在有权消防机构的等效电子有效检查记录时可依学校允许机制核；申请早期未有现场报告属于阶段性未形成，不自动将申请人定为弄虚作假。
- evidenceAnchors: event_version、venue_id、现场检查日期、主管机构、合格/整改、当前场次、官方可核记录。
- failureMode: 将专业后置检查当申请人初次递交即必有附件，或把消防合格记录当整体活动批准。
- confidence: 高（28号令适用并已明确时），校本表单形式 U。
- unresolved: 2026校内“何种活动称大型”，承办单位如何约定现场检查预约流程。
- reverseInterpretation: 如果活动不符合第15条范围，不能使用本对照硬性拒件；若消防措施有实质变更，既有检查记录是否覆盖新版本还需有权认定。

### F-PAIR-04｜同一施工人和地点：非明火设备安装与电焊维修

- dutyId: F-G04-SRC-03/F-G04-SRC-04/F-G04-SRC-05/F-G04-SRC-09。
- sourceLocator: 第28号令第17、22、23条；成都理工大学2025-12-02冬季消防通知第三部分(四)，https://bwc.cdut.edu.cn/info/1033/2307.htm
- applicability: 同一外包工人在同一校内在建工程、同样承担现场安全责任的施工单位、相同学校用人单位、相同校门入校资格是否有效（**均未验证，保持 U**），其余工程合同、地点、时间不变。假定操作不是禁止动火的特殊场所，且相关人具备对应工种法定资质（本对照不评估资质证书）。
- changedFact: A = 只做不产生明火/火花的固定架安装；B = 改为需要动火许可的电焊作业。**作业类别是唯一变化项**。
- expectedDecision: A = 第22条所指特殊电气焊明火审批触发条件在已给事实上不成立；仍保持第17条施工现场及第23条外来务工消防管理责任。B = 第22条所指学校消防机构审批、监管及措施成为额外独立事项；若未核实有权许可则 PENDING_FIRE_APPROVAL，不可因已准入校门/有合同自动开工。
- admissibleAlternatives: 若装配过程实际伴随打磨火花，需更正作业类别后重新判定；现有正式审批记录需以真实校方有权系统复核。
- evidenceAnchors: 作业方式与设备、施工部位、施工工单版本、用工关系、学校消防机构批准范围和时间、监护计划。
- failureMode: 校门准入证或施工合同代替明火审批；不动火事项被误强制提交焊接许可证。
- confidence: 高（28号令明火与施工责任边界），具体CDUT门禁、工种资质与学校许可表均 U。
- unresolved: 本校2026施工人员长期校门授权规则、动火票具体格式及期限；本对照不决定它们。
- reverseInterpretation: 不能用“第22条曾明确电气焊”等价断定所有实验加热/任何高温都必须按施工动火申报；应先证明它属于所指危险或特殊动火条件。

## S / U 评估边界

- **S = 0**：本轮没有设定虚构学校规则，也没有借想象的“长期驻场30天/7日”之类数字补齐未知。
- **U = 6**：具体参见 independent-source-register.md 中 U-G04-01..06。源缺失时输出待核/询问有权部门，不判真实CDUT拒件。
- 以上 F-PAIR-01..04 为 **4组逻辑上单变量的、有真实官方来源范围条件的研究反例**；未向现有 C 或 D 进行逐条运行/评分，因此 **可区分案例数=4，复现作者业务缺陷数=0**。
