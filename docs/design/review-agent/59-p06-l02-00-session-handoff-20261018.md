如果私有原始资料并不存在或未经授权不可访问，必须在对应字段写 MISSING/UNDETERMINED，**不能重新制造一个合成输入来冒充原 C 案的同一运行**。新的合成运行可以独立开立，在报表中标明 NEW SYNTHETIC、独立 case/run ID 和版本，不能与旧 case 相互替换。

归因使用 CORRECT_DENIAL / BUSINESS_INCOMPLETE / EXECUTION_FAILURE / HARNESS_INVALID / UNDETERMINED 五类，另分 RECOVERED_OLD_DEFECT / NOT_REPRODUCED_IN_NEW_CASE，必须有对应证据才能下判断。队列 done 与 V2 completed 不等于业务审批。
