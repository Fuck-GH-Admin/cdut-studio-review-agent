## 本地环境及工作树

Bun 1.4.0；推荐 Node 22。若已经 clone 仓库，略过首次 git clone 命令。

~~~bash
git clone https://github.com/Fuck-GH-Admin/cdut-studio-review-agent.git
cd cdut-studio-review-agent
git fetch origin feat/d4-all-domains-integration-r01
git worktree add ../cdut-d4-unified -b local/d4-unified-smoke origin/feat/d4-all-domains-integration-r01
cd ../cdut-d4-unified
git rev-parse HEAD
bun --version
export ELECTRON_SKIP_BINARY_DOWNLOAD=1
bun install --frozen-lockfile
bun run typecheck
bun run check:boundaries
bun test --isolate --timeout 120000
bun apps/electron/scripts/review-d4-unified.ts verify
~~~

先记录 git rev-parse HEAD，然后与 PR #97 最终 HEAD 比对。verify 检验固定 workspace 的 Git blob SHA1、模板 ID/版本、D1 来源与作者态验证、D3 export/import、一套现有 D2 技术预审候选壳及可识别的受控合成 selection/case。它不是在线 Pi 的语义准确率验收；无法自动定位 fixture 的 G01-I 需另行执行对应领域专项测试。

## 把 50 套候选显式导入原有 TemplateStore

不要使用真实用户的配置路径。写操作前必须使用隔离目录。

~~~bash
export PROFER_CONFIG_DIR="$(mktemp -d)"
bun apps/electron/scripts/review-d4-unified.ts list > /tmp/d4-unified-catalog.json
bun apps/electron/scripts/review-d4-unified.ts install
bun apps/electron/scripts/review-d4-unified.ts installed
~~~

期望 installed 结构为 expected=50、candidateHeld=50、visible=50、missing=[]。可通过 install g08-t02 单独加载一套，重复安装会跳过现存 candidate-held 草稿，不覆盖正常模板或已发布模板。由现有 TemplateStore.listTemplates() 与 IPC 列出候选壳。

如果要在客户端界面看到刚刚安装的模板，务必让 Electron 进程使用**同一个** PROFER_CONFIG_DIR。测试时恢复 Electron 下载配置并启动：

~~~bash
unset ELECTRON_SKIP_BINARY_DOWNLOAD
bun run electron:dev
~~~

**重要：** UI 中出现的壳不是静态的完整审核规则集。真实 50 套责任在 D1 workspace 及按对象 D2 Plan 内，必须经 D2 create/attach。直接通过通用模板向导只选壳创建空案卷，不等于运行 D4 规则；当前并未开发完整 D4 专用 GUI 情景路由器。模板的 candidate-held 发布限制不能通过普通编辑解除。

## 故障定位

| 错误或现象 | 优先核验 |
|---|---|
| D4_WORKSPACE_BLOB_CHANGED | 工作树/分支及 Git blob SHA，被意外改动时停止；不能悄悄替换来源 |
| D4_CATALOG_INVALID_* | catalog、各域 manifest、50 个唯一 templateId 和版本 |
| D4_D1_INVALID / D4_D3_TRANSFER_DRIFT | workspace 源绑定、D3 锁、原领域专项测试 |
| D2_GENERIC_* / D4_D2_PLAN_INCOMPLETE | objectKey、subjectId、互斥 primary、三值 conditions、sourceVersionId、EvidenceLink 所属版本 |
| D4_EXISTING_TEMPLATE_NOT_CANDIDATE | 本地已有同名普通模板；更换隔离配置目录，不覆盖用户模板 |
| installed=50 但 UI 无模板 | PROFER_CONFIG_DIR 是否一致、listTemplates IPC 与模板过滤器 |
| 历史 Pi 回执指纹与新 Plan 不符 | 回看源 PR 固定代码、Plan 和原合成选择；新 HEAD 上必须重新执行，不能复制旧回执 |
| bun test 全仓失败 | 保留原始日志，区分公共引擎回归、单领域故障、跨域冲突；不能关闭失败测试 |

本地 Agent 应回传：最终 commit SHA、Bun/Node/OS、frozen install、typecheck、boundaries、全仓 bun test 原始日志、50 项 verify 与 installed 输出、至少两领域 D2 互斥/叠加/unknown/对象隔离反例及 Pi Run 与 Plan 指纹、全部阻断归因和复现命令。

仍有正式校方制度版本、OA/学籍/财务权限和在线模型语义测试缺口时维持 candidate-held；统一工程未实际完全验收前 D4_UNIFIED_INTEGRATION=PARTIAL。
