## 定量与用户品质门槛（原始设计提出，尚未达到）

1. **模型评测设计**：按六类内置模板各20案，合计120份可分发的虚构/授权样本，另有30份不参与Prompt调整的盲测；两名业务标注者独立核对并裁定差异；每一固定关键样本对同一模型运行至少三次。注意这只是目标评测集而非已经建成、也不意味着现有50个G域技术候选等同六类已发布模板。
2. **可验证的模型/来源质量**：100% 导入文件/页/Check状态登记，100% 确定计算正确与真正存在且属于正确版本的确定引用；原始方案拟定来源支持率≥95%、影响通过或拒绝的关键固定项100%，明确违规召回≥95%、精确率≥90%，歧义正确待确认≥95%，清晰电子关键字段提取≥95%；这些须按业务类型、材料与模型版本分项测量，不可用合成stub替代模型效果。
3. **真正可使用的产品**：正常人从零用普通界面创建第七种业务，无需工程师写JSON；原始目标为5名非开发者中至少4名30分钟内完成配置、试跑、发布；普通用户导入原件并有准确SourceFocus、可以人工纠正/补件/申诉/独立评审/离线/报告；所有实例历史不会为了“统一UI”丢掉。
4. **规模与减负**：原始100案/500文件队列可管理、单坏件不拖垮无关案；同标注任务中整理/重复输入动作减少≥70%，人工活跃时间减少≥50%（需同群体对照，不把等待模型算节省）。记录输入登记反馈目标、stop反馈、耗时P50/P95、CPU/内存/磁盘、安装依赖和目标Windows安装验证。
5. **权威边界**：C类本地/Mock通路可独立验收，S类真实身份/跨设备/学校写入必须独立授权签名。发布不允许通过模拟回执、政策临时示例或路径存在性冒充校方业务已接受。
