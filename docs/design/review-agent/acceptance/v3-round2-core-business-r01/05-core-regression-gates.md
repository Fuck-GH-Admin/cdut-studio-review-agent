- **身份用例**：renderer 向未重绑定的 `CORRECT_OBSERVATION_V2` / `SET_EVIDENCE_LINK_V2` 发 `actorSource:'school', role:'teacher'`。预期 Main 绑定本地 reviewer 或拒绝；需同时检查 Receipt actor、权限和无部分写，而不仅仅验证 API 抛错。代码路径缺少统一 `bindLocalReviewerCommand` 是已证事实，但尚无动态实测。
- **申诉用例**：[`apps/electron/src/main/lib/review/review-ipc.ts:721`](https://github.com/Fuck-GH-Admin/cdut-studio-review-agent/blob/db0284879f75ce123b5d83cb6577a3cc7ad057da/apps/electron/src/main/lib/review/review-ipc.ts#L721) 的 `RESOLVE_APPEAL_V2` 重绑 local reviewer，而 [`apps/electron/src/main/lib/review/stage-workflow.ts:322`](https://github.com/Fuck-GH-Admin/cdut-studio-review-agent/blob/db0284879f75ce123b5d83cb6577a3cc7ad057da/apps/electron/src/main/lib/review/stage-workflow.ts#L322) 强制 `role==='teacher'`。现有桌面 IPC 正常路径将稳定拒绝复核教师操作，除非另有可信调用链；故**申诉服务实现不等于该 IPC 可完成用户复核**。应增加学校授权入口并做双角色正反例，不能伪造 teacher 绕过。
- **观察值优先级**：`recordObservation` 只追加，`latestObservations` 按时间键选新一条；应补“人工确认→AI 新候选→正式有效值仍为人工确认或进入明确冲突待确认”的 E2E 负例，不直接假定当前业务都按它读。
- **离线包 fail-closed**：`importHandoffPackage` 当前无 expectedExternalRevision 的调用只返回 HASH_MISMATCH；但 `applyRoundTripPackage` 的其他 `ok:false` 落入原始 payload，应补 mock `CONFLICT` 与新增错误码处理，避免后续集成改变而意外默认放行。此为未来边界兼容测试，不是当前已证漏洞。
- **报告差异**：`report-export-v2-service` 当前输出 Markdown 文件。不要把存在 EXPORT_REPORT_V2 误记为 PDF/XLSX 验收合格。
