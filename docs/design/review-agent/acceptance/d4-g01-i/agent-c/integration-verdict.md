# C0 独立阶段验收意见

**STRUCTURAL_CANDIDATE_ONLY；BUSINESS_RUNTIME_NOT_RUN；GOLD_UNREAD。**

1. **A：** 固定提交中的模块化工作区、来源映射和 49 条语义 Check 具备可审计结构，不能认作 28 案已绑定有效 Subject/SourceRef 的动态运行模板。A 自有测试不等于 C 的独立执行。
2. **B：** r02 输入真实哈希匹配；120 个无 CRC 错误实体文件、28 个唯一案例、28 个模拟可信夹具、119 个清单项、59 个材料索引全数一致；输入不包含 Gold 标记。完整 Gold 是否可独立复核，C1 尚未开展。
3. **交叉运行：** 当前 B 的真实 Student/Field/Claim/Evidence 契约与 A 的 0-Subject/0-Target D2 计划不无损匹配。28 案的输入完整性检查 PASS；**28 案产品运行 NOT_RUN、兼容性 BLOCKED_ENGINE、Gold 比较 NOT_RUN**。没有伪造 Case ID/Run ID。
4. **归因：** 优先是 D3/D2 公共能力缺口，兼有校本制度 POLICY_HOLD。A 模板错误和 B Gold 错误目前都不能确定，禁止用静态检查把它们分配为 FAIL。
5. **顺序：** 先支持 G01 typed student/field Target + 多轴动态选择（最大覆盖杠杆）；再支持区分 applicant claim / trusted source / documentVersionId 的输入门禁；第三补一证多事实/合法替代和版本图；随后学校有效政策和阶段责任配置；最后在固定 A/B 资产下实跑 28 案、对照分阶段授权 Gold。

**发布建议：** G01-I 可继续作为 D4 有限技术候选进行修复，不可标为业务运行验收 PASS、官方校规/审批资格或线上模型准确率。下一轮开发只需最小公共扩展，勿修改 A/B 原件或退化为校园卡/档案申请。
