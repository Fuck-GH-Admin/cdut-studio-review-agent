## Failures, recovery, and limits

No product defect was found and no product-code fix was attempted. The first two launcher attempts stopped on the packaged SUID sandbox-helper configuration; a third attempt stopped because its Xvfb process had ended with its tool session. Attempt four ran successfully on a persistent Xvfb session. These environment failures and raw logs are preserved privately. A native-select calibration initially landed on adjacent G08-T03; it was corrected with paced visible keyboard navigation before any create action. One submit click landed above the button and left the dialog open; the button’s visible coordinates were queried and the case was then created successfully. These did not create extra cases or indicate application failures. The private recovery log records the exact sequence.

Not run: P1-C routing/countdown, P06, model-provider setup or model execution, G08’s full 107-item review, G01 synthetic-case creation, a real student registry or school account, document/evidence import, and formal approval/signature flows. The generic published-template loader on the fixed G03 case was inspected but not changed; this run does not assert broader template-version switching behavior.

Given the complete G03 GUI-to-D2 path, same-process reload, G08 and G01-I boundaries, and B-03 validation, **recommend beginning P1-C**. That next phase must separately validate its own acceptance criteria; this verdict does not authorize online review or school action.
