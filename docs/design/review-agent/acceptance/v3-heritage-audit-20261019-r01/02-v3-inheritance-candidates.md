## 原则性判断
- **REUSE** 仅建议对边界较清楚的纯能力单元做进一步直接复用核验，如 V2 CAS、D3 digest 锁、覆盖账本、批次版本锁、保守分流与小型角色解析。不能把其外部调用链一并默认签收。
- **REFACTOR** 是保留产品/安全不变量但重新整理对象与边界：V1/V2 双重案卷写入、D4 建案与 P06 执行双批次、普通 Pi 与审核专用权限、Run/来源/反馈展示。
- **REIMPLEMENT** 是能力保留、现实现不适合作为基础：基于两个硬编码 SIGNALS 的全域路由、外部 SchoolPort 真接入、大结果处理的隔离实验。
- **PRESERVE_TESTS** 实验与负例即使不保留复杂旧代码，也应转成固定输入、错误码、被阻断原因与回归脚本。**RETIRE** 仅是实现候选，不等于删掉原用户场景。
