# P2-A-002 — no directly reusable D3 author Pi material-smoke command

- **Status**: usability gap, open on public D3 tooling; author-side integration scripts are stopgaps. `owner`: D3 CLI/agent workflow, not business policy.
- **Code baseline**: `d16f047af653f7ba259456807c1fc150e9d0f417`.
- **Repro**: D1 and D2 CLI provide `validate/save/read/diff/preview/register/create`, but no documented public CLI accepting a synthetic material and driving `registerMaterial` → `preparePiReviewRunV2` → `submitPiReviewResultV2` → `verifyD2PiRun`. Agent A had to author `tests/pi-synthetic-interface.ts`, debug block/quote SourceRef mismatch and maintain a second script for three independent Check statuses.
- **Desired outcome**: D3 should ship **one copyable, stable smoke-test entrypoint** that accepts a candidate workspace, D2 selection, synthetic text files, independent expected-status JSON and output directory; it must always use new isolated config, create an actual technical candidate/case, register the active document versions, prepare a Pi run, submit synthetic results through the *existing* Pi service, and verify the resulting ledger/Check denominator/fingerprint/SourceRefs. It must expose case/run IDs and real command exit codes.
- **Contract proposal, NOT an existing command**: `bun apps/electron/scripts/review-d3-pi-smoke.ts --workspace <workspace.json> --selection <selection.json> --cases <synthetic-matrix.json> --out <output-dir>`.
- **Test boundaries**: distinguish `structuredToolReceipt:synthetic` from `onlineModelRun:not-run`, reject source-less definitive assertions and wrong block/version citation, preserve awaiting-confirmation for unreadable content, fail on omitted mapped Checks, never claim school approval.
- **Source/affected**: `tests/pi-synthetic-interface.ts` and `tests/pi-granularity-interface.ts` are real standalone examples but still TypeScript and do not satisfy the generic CLI handoff requirement.
- **Closure**: another first-time author can run a documented short command with only JSON/text inputs, no custom TS, and retrieve detailed real D2/Pi stdout/exit/coverage and exportable artifacts; verified against fixed SHA and independent sources.
