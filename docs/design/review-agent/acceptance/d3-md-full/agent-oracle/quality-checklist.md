# D3-MD-Q1 独立质量验收门槛

## 判定状态

- **PASS**：以原 MD 为真值，独立静态对照和相应真实可执行测试均有充分证据且没有关键语义偏离；仅限被核范围。
- **FAIL**：确有丢责任、权限串用、越权批准、非法缺件/过度拒绝、伪造证据来源，或者应独立判断的结果被吞没。
- **NOT-RUN**：本轮并未执行真实 CLI/模型或没有 Run；不能用模拟预期换成 PASS。
- **BLOCKED-BY-SOURCE**：原始 MD 缺失/错误哈希，或某项必需校规来源未取得；分清是整份业务真值源还是特定学校规定。
- **TOOLING-BLOCKED**：冻结 D1/D2/D3/Pi 的合法输入无法无损表达；需错误码、复现命令、关联原 ID、反例与缺口报告，不得更改其他人的内核来掩盖。

## 强制核对项（统一验收者逐项签名）

| 门槛 | 判定依据 | 失败标准 |
|---|---|---|
| Q01 原文真值 | 原 MD 原始字节 SHA 与 103 个源职责锚点 | 摘要不一致仍宣布业务 gold 完成 |
| Q02 Rxx 无漏 | R01–R42 每条唯一有效处置、范围、理由 | 只有一个“已审核全部内容”的聚合 Check |
| Q03 分支与例外 | B01–B15、E01–E16 激活真/假/未知与反误杀案例 | 未知被当 false、材料例外消失 |
| Q04 材料和阶段 | S01–S14 适用学校/办理阶段/提供者/替代匹配 | 要求申请人提前上传馆方批准和归还记录 |
| Q05 操作与主体 | `case/item/operation` 与个人/单位/有权机关绑定 | 查阅权限被用于复制/另案/过期请求 |
| Q06 实际计划 | 每项宣称实现的行为可追至 D2 `Rule/Check/Subject` | 无真实 Check，或 Check 使用错误 subject |
| Q07 权威隔离 | SourceBinding 来源与学校/时间/规则范围核对 | `CROSS_SCHOOL`/`CONFIG_PENDING` 被升为 `verified` |
| Q08 缺口诚实 | Tooling 缺口有真实命令/错误及责任 ID，手工权限可见 | 高级关系不支持却记为已执行 |
| Q09 金标反例 | 30 案的输入仅含合成材料，预期独立保存、逐 operation 评分 | 仅比编译成功不查行为差异；输入泄漏 gold |
| Q10 证据真实性 | Case ID、真实 Run ID、SourceRef、文件版本、拒止日志可复核 | `runEvidenceRefs` 凭空填写、未读材料伪通过 |
| Q11 生命周期 | 冻结引用 digest/旧案卷快照不漂移；变更后新版本重审 | 编辑草稿直接改写历史 Run |
| Q12 最终审批门禁 | 预审交付标记始终 false，外部执行回执才能展示实际状态 | 模型替馆方批准、签章、交付 |
| Q13 状态多轴 | `evidence/permission/policy/stage` 与理由可分别读取 | pending 和 denied 或 missing 混用 |
| Q14 外部生效性 | 本校2026三表原件、2017/2024规章、渠道/角色有效版本 | 仅核原文就宣称本校强制校规现行 |

**硬拒止**：Q05/Q07/Q08/Q10/Q12 任何未经解决的越权风险不得整体 PASS；政策未取得不能以猜测方式修成绿色。对未运行的一律 NOT-RUN。

## 最终交叉流程

1. 独立审计者校验私有原 MD；不要从 Agent A 结果里反推出 gold。
2. 读取 Agent A `conversion-ledger`、作者态模块实例、source binding、真实 D2 candidate plan 和已登记 gap；逐源 ID 建立双向映射。
3. 对每个独立 Rxx 检查 scope、触发、排除、unknown、exemption、来源权限和实际 RuleSpec；允许语义等价但结构不同。
4. 用本测试集 **仅 cases** 导入执行、保留原始输出，随后单独评分 against **expected**；真实不可执行的输入标 TOOLING-BLOCKED，不能删除用例。
5. 使用既有 `apps/electron/scripts/review-d3-md-coverage.py` 做机器对照，核其 JSON 并按人工语义校验补足其盲点。
6. 验证文件、冻结模块 digest、导出重导入、旧案卷版本变化；明确每一层实际运行状态。
7. 按独立源 ID 逐项给 PASS/FAIL/NOT-RUN/BLOCKED-BY-SOURCE/TOOLING-BLOCKED；没有两个作者中途交换产物。

## 最终通过条件

完整 R01–R42、分支、材料槽、例外和正文不变量无未记录漏项；所有已宣称可运行的职责有真实 D2 映射与反例证据；不能执行的留明确 gap 并不得伪装通过；对特定未核校本制度保持待核，不认定学校已正式上线。**全 103 项结构覆盖不是 103 条人工行政决定被完成，也不是 103 个独立编译 Check。**
