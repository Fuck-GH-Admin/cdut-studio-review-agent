## 非 R 表格义务

- **B01–B15**：包括规则版本、角色组合、独立操作、开放状态、限制、渠道、阶段、时间窗、份数范围、身份接口、电子替代、混合申请等 15 条三态触发。校本有待确认的触发不能塌缩为 false。
- **S01–S14**：槽是证据用途而不是文件名；阶段、材料提供者与合法替代是同一个槽的三个约束。S09、S10、S12 等有外部部门责任；申请阶段不强制索要未来的批准、借还回执。
- **E01–E16**：从历史姓名、更名、旧学号、未知档号，到代理复合角色、电子委托、过期渠道公告、第三人隐私、OCR失败、仅授权一页等，作为逐项反误杀回归，不应因“已覆盖 Rxx”而删除。
- **P01–P16**：额外采样出正文明确的操作稳定键、四角色隔离、跨操作附件引用、可信馆方状态、三态触发、双时钟材料、并存冲突、输出交付硬门禁、旧案卷不可漂移、人工结论具名等文本不变量。具体原文锚点见 JSON。
