## Exact gap
Current C0 ExecutionEvent is:
  schemaVersion, attemptId, generation, sequence,
  eventKind: read-receipt-proposal | check-proposal | stopped | failed,
  toolReceipt: receiptId/permissionGrantId/sourceVersionId?,
  manifestHash.

It cannot independently express:
- unique eventId for durable shared dedupe/ACK; attempt/generation/sequence identity is usable but not formally committed;
- frozen plan and caseRevision/Run binding, scope, checkKey+targetKey+objectKey;
- accepted/rejected/missing/unknown, diagnostic reason, partial, timed-out, needs-resume, cancelled;
- block/page/region coverage and actual read extent; receiptId alone cannot prove full source read;
- explicitly sealed terminal state and verified ACK semantics.

## Proposed DTO_after (requires Dev-C decision)
Add fields to an authorized ExecutionEvent versioned extension or new frozen schema revision:
- eventId: stable 64-byte lowercase hex digest or UUID generated by Main-owned execution adapter;
- caseId, runId, caseRevision, frozenPlanFingerprint, inputManifestHash (or explicit binding to trusted RunEvidenceIdentity);
- grantedScope/ownerGrantId with validated source version+block identities;
- eventKind expanded to terminal and diagnostic variants; check proposal explicitly carries (checkKey,targetKey,objectKey,subjectId, outcome);
- read proposal explicitly carries (documentVersionId, rawSha256, parseRevision, block/locator, full-vs-partial);
- technical terminal enum: completed-technical | partial | cancelled | timed-out | needs-resume | failed;
- consumedAt/ACK identity belongs ONLY to Dev-C receipt, not self-proclaimed by Pi.

Dev-C Main validates every field against its own pinned RunEvidenceIdentity, frozen Plan, Source allowlist, active grant generation, sender binding, expiry and authoritative Case/Source status; no Pi/Renderer assertion suffices.

## Required security/compat tests
Positive: two owners/two attempts; strict per-attempt sequence; replay and duplicate ACK; accepted 9/9 check/target coverage; one-page vs full-document read.
Negative: forged source/hash/quote, cross-case; post-await revoke; old generation replay; missing/rejected/unknown 1/9; 24-turn exhaustion; duplicate with changed contents; stale plan and caseRevision; disk-full ACK failure.
Rollback: refuse proposed extended version, remain C0/1 read/check/stopped/failed proposals without false complete; revert schema/bridge to C0 SHA and discard non-ACKed expanded event versions after audit, never synthesize a Run.
