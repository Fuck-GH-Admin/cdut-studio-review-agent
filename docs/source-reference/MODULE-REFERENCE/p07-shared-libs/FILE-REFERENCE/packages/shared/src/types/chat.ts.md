# packages/shared/src/types/chat.ts

## 1. 结论与边界

Chat 模块核心契约（`:1-6`）：附件/消息/对话/分支树/搜索/发送/标题/流式事件/模型选项/分页 共 33 个导出（31 类型 + 2 常量），`CHAT_IPC_CHANNELS` 42 键是 Chat 的 IPC 协议总表。消息以 `parentId` 构成 DAG，`ConversationMeta.activePath` 定展示链。

不做的事：无校验/无逻辑（值级代码仅 2 常量）；IPC 注册与桥封装在 main/preload；持久化在服务层。

## 3. 内部逻辑与关键流程

### 3.1 消息 DAG 与标题状态机（注释级契约）

- `parentId` 构成 DAG/链（`:149-155`）：一条 user 消息可有多个 assistant 子节点；展示链 = `activePath`（空/缺省取首条消息为起点，`:239-243`）。
- 标题三字段状态机（`:234-238`）：`titleAutoGeneratedAt` 存在=自动产物可精修；缺失且非默认名=用户手动命名（自动流程永久退让）；`titleRefineAttempts` 达上限停；`titleLockedAt` 存在即锁定。
- 发送去重（`:361-364` 注释）：`pendingUserMessageId` 给定时 `sendMessage` 不追加重复 user 消息且从模型历史剔除该节点。

### 3.2 `CHAT_IPC_CHANNELS` 42 键（`:522-618`）

分组（注释 `:523`/`:543`/`:569`/`:593`/`:601`/`:607`）：对话管理 9（`LIST_CONVERSATIONS`/`CREATE_CONVERSATION`/`GET_MESSAGES`/`GET_RECENT_MESSAGES`/`UPDATE_TITLE`/`AUTO_TITLE:535`/`REGENERATE_TITLE:537`/`DELETE_CONVERSATION`/`UPDATE_MODEL`）；消息发送 12（`SEND_MESSAGE:545`/`ADD_KNOWLEDGE_REFERENCES:547`/`STOP_GENERATION`/`DELETE_MESSAGE`/`TRUNCATE_MESSAGES_FROM`（**已废弃**，`:552`）/`GET_BRANCH`/`SET_ACTIVE_PATH`/`GET_BRANCH_TREE`/`FORK_BRANCH_AT`/`GET_MESSAGE_CONTENT`/`UPDATE_CONTEXT_DIVIDERS`/`GENERATE_TITLE`）；附件 11（含 `PARSE_PAPER`/`PARSE_PAPER_BY_PATH`/`ESTIMATE_PAPER_PAGES`）；置顶管理 3（`TOGGLE_PIN`/`TOGGLE_ARCHIVE`/`SEARCH_MESSAGES`——搜索混入该组，见矛盾③）；教程 2；流式 5（`chat:stream:*` 多一层命名空间，`STREAM_CHUNK/REASONING/COMPLETE/ERROR/TOOL_ACTIVITY`，`:607` 注释：主进程→渲染进程推送）。

键值规则：41/42 为键名 kebab 化；**唯一例外** `UPDATE_MODEL='chat:update-conversation-model'`（`:541`）。

## 4. 调用者与调用链

- preload 桥（`preload/index.ts` chat 段 `:2351-2457` 等；`SEND_MESSAGE`/`ADD_KNOWLEDGE_REFERENCES`/`STOP_GENERATION` 在桥上有孤儿注释无成员——见 nb-05b 手册矛盾册矛盾①②，本契约定义了通道但桥未封装）。
- main `ipc.ts` chat handler 族；渲染层会话 UI（`ChatView`/`BranchTreeView`/模型选择器 `:479`）。
- 出向：`ProviderType`（`./channel`，`:491`）、`KnowledgeReference`（`./knowledge-base`，`:180`/`:356`）。

## 5. 数据 I/O、读写与副作用

纯类型 + 2 常量；无 I/O。持久化线索（注释）：`conversations.json`（`:208`）、主 JSONL（`:274`）、sidecar `.discarded.jsonl`（`:131`/`:134`）。

## 6. 分支、失败、取消与恢复

不适用（无控制流）。语义承载：`StreamErrorEvent.code?/errorTitle?`（`:439-441`）供 UI 结构化引导；`STOP_GENERATION` 通道是取消入口；`DiscardedSegmentRecord.reason` 三分支（`:142`）。

## 7. 权限与权威状态

- `knowledgeReferences` 归一权威在主进程（`:355`）；资料实体独立于消息（`:179`）。
- `ConversationMeta` 是对话元数据权威（标题锁定 `:238`）；`activePath` 合法性（从 `parentId=null` 根开始）由后端校验语义（`:243`）。
- `MAX_ATTACHMENT_SIZE` 是附件闸值；`ChatImageMediaType` 白名单拒绝 SVG 等可执行类型（`:48`）。

## 8. 修改影响面

改字段影响消息 DAG 渲染、发送链、标题状态机、搜索；`CHAT_IPC_CHANNELS` 改名需同步 preload 桥/main 注册/renderer（注意已缓存 preload 兼容惯例，agent.ts:2058 同例）；`runId` 语义（丢弃迟到事件）改动影响流式消费。
