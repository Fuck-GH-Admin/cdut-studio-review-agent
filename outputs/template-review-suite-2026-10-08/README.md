# 审核模板完整案卷测试材料

测试套件目录；所有数据为合成数据。逐模板审核结论见 [`RESULTS.md`](RESULTS.md)，机器可读汇总见 `run-results/verification.json`。

- `cases/<template-id>/rules.md`：公开规则与适用边界
- `cases/<template-id>/application.docx`：合成申报材料
- `workbooks/`：合成成绩与预算工作簿
- `cases/shared/synthetic-scanned-certificate.pdf`：明确标注的扫描图像样张
- `suite-manifest.json`：测试场景和预期观察项（不上传至审核案卷）
- `PUBLIC-SOURCES.md`：公开来源、链接和适用范围说明
