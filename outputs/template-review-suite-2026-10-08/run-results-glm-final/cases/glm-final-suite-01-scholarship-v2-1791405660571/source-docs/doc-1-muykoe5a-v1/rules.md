# 学生奖助学金申报与评审 测试材料规则来源

**范围声明：**本文件用于隔离的合成流程测试，不是正式校规、申报通知、财务审批或法律意见。所有测试身份、编号和金额均虚构。

## 公开来源与适用边界
### 教育部、财政部《本专科生国家奖学金评审办法》
- 来源：https://www.moe.gov.cn/srcsite/A05/s7505/201909/t20190930_401817.html
- 适用范围：只适用于本专科生国家奖学金。明确材料完整性、程序规范性、条件相符性；成绩和综合考评均前10%，或均进入前30%并提供经学校审核盖章的突出表现证明。各校仍须有当年实施方案。
### 成都理工大学2025年本专科学生资助政策简介
- 来源：https://xsc.cdut.edu.cn/info/1032/3429.htm
- 适用范围：学校2025年资助政策介绍，不替代当前年度/项目的评审通知与细则。

## 本次审核的规则边界
国家奖学金门槛按上述教育部办法列示。一般奖助项目须另附对应项目本年度正式通知；本案综合考评排名 18/120，不能在缺少校内盖章突出表现材料时自动通过例外条件。

## 测试要求
- 只把来源文件中明确写出的内容当作外部规则。
- 缺少校内当年通知、审批、积分映射、授权签字或有效性确认时，标记待确认，不要猜测。
- 证据需要引用案卷中的具体材料与可定位位置。
- 本文件并非本次模拟数据的答案。
