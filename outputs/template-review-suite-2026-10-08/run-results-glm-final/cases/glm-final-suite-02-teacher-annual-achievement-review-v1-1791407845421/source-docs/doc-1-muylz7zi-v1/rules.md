# 教师年度教学科研与服务材料核验 测试材料规则来源

**范围声明：**本文件用于隔离的合成流程测试，不是正式校规、申报通知、财务审批或法律意见。所有测试身份、编号和金额均虚构。

## 公开来源与适用边界
### 教育部《关于深化高等学校教师考核评价制度改革的指导意见》
- 来源：https://www.moe.gov.cn/srcsite/A10/s7151/201609/t20160920_281586.html
- 适用范围：高校教师考核评价指导性要求强调分类评价、教学科研社会服务等维度；不给出成都理工大学某年度工作量阈值或绩效分值。
### 教育部关于新时代教师评价改革的说明
- 来源：https://www.moe.gov.cn/jyb_xwfb/xw_zt/moe_357/jyzt_2020n/2020_zt21/dajizhewen/202010/t20201019_495605.html
- 适用范围：教师评价改革原则；不构成校内个人年度考核计分标准。

## 本次审核的规则边界
公开指导文件未给出本校本年度个人工作量阈值、岗位类型系数或绩效换算公式。任何数值结论都需留给人事/学院确认。

## 测试要求
- 只把来源文件中明确写出的内容当作外部规则。
- 缺少校内当年通知、审批、积分映射、授权签字或有效性确认时，标记待确认，不要猜测。
- 证据需要引用案卷中的具体材料与可定位位置。
- 本文件并非本次模拟数据的答案。
