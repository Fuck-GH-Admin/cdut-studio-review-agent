# G04 首次独立 E1｜independent-source-register

> 研究性质：前比较（pre-comparison）独立源事实调查；不签 E PASS。只读第28号令、第505号令和成都理工大学公开正式来源；未阅读 C 母版、D Gold、旧 E 审计缺陷/答案或 A/B 作者语义判断。本登记记录法定及学校公开可证范围，不生成“已经批准”的事实。

## 0. 核验与适用方法

- 调查时间：2026-10-16（UTC+08:00）；全文发布与施行日期见各项来源；网络检索结果随时间变化。
- F = 可定位至现实官方来源的事实（标注其实际核验深度）；S = 明确封闭的反事实/模拟场景（见反例文件），不代表真实学校制度；U = 尚无当前权威资料可判定的现实问题。
- 法源层级：**国务院第505号令**管理法定大型群众性活动的公安安全许可；**教育部/公安部第28号令**管理高校消防事项，包括特定校内大型活动现场消防检查和施工；**成都理工大学正式网页**仅证明网页所列学校部门职责或当次通知要求。三者不是同一张申请表，不可视作互相替代。
- 获取限制：国家行政法规库第505号令正文可直接访问；第28号令对照教育部正式公开条文检索结果及国家消防救援局公开转发；成都理工大学 bwc.cdut.edu.cn 原站在本次直开时返回 HTTP 412，校内事实依据搜索服务抓取的原域名官方网页正文摘录，而**非**本站所有附件/规程全文的直接阅读。因此本校细化手续和时效不可外推。
- **法律动态提示**：第28号令部分措辞仍以“公安机关消防机构”表述建设工程手续；不据此推断2026年住建/消防救援等行政审批机关的现行分工。需要额外当期法定来源时标 U。第505号令司法部行政法规库页面在本轮显示2007年施行、无列示修订沿革。

## 2. F｜源事实卡（条款／学校／主体／时间／强制性／授权动作与输出状态）

**F01 · 28号令，第2、4、11、12条**｜范围：全国普通/成人高校（含成都理工大学）及相关驻校单位；主体：学校、校内二级单位及驻校单位，其主要负责人承担本单位消防安全责任；阶段：持续管理；性质：强制责任制。可证状态：应落实责任、需履行本单位管理职责；**不能推得**学校某一审批表或某人的实际签字。权责：学校及相应单位负责人。来源 L28。

**F02 · 28号令，第10条第（五）（九）项、第11条第（八）项**｜范围：高校消防；主体：学校消防机构、校内和驻校单位；时间：校内动明火作业前、建设工程或装修等校内备案审查阶段；性质：学校消防机构审批校内各单位动用明火作业、受理有关工程的校内备案审查，校内二级单位新建/扩建/改建及装饰装修工程应报该机构备案。输出：校内消防动火审批、校内工程备案审查；**不能**当作其他政府部门法定行政许可。来源 L28。

**F03 · 28号令，第14条第（一）（十）项**｜范围：高校消防重点部位；主体：学校及施工现场主管部门；时间：持续；性质：体育场馆、会堂等人员密集场所及建设工程施工现场属消防安全重点部位范围，须按规定严格管理；输出：重点部位管理/巡查要求，**不是**自动批准活动或施工。来源 L28。

**F04 · 28号令，第15条**｜范围：**在学校内举办**的文艺、体育、集会、招生、就业咨询等大型活动和展览；未给出“1000人”的通用限定；主体：主办单位和学校消防机构；时间：**举办前**；性质：主办方落实消防设施、通道、疏散预案和演练，学校消防机构对现场检查合格后方可举办；依法还须地方政府有关部门审批的，取得后方可举办。输出：现场消防检查合格/未合格/待查，与外部行政审批分别记录。不得将此条扩大为“一切小型课堂活动均需同级检查”，校内“大型”的具体认定留 U。来源 L28。

**F05 · 28号令，第17条**｜范围：高校的新建/改建/扩建/装修/装饰及校内施工现场；主体：建设相关单位、施工单位、学校消防机构、校档案机构；时间：工程前依法办理适用手续、施工中监督、竣工后备案；性质：须执行消防技术标准及依法适用的建设工程消防手续，**施工单位负责施工现场消防安全**并接受学校消防机构监督检查，竣工工程资料报学校档案机构和消防机构备案；消防设施招标和验收应有学校消防机构参加。输出：校内工程备案/施工中检查/竣工资料备案等彼此不同的状态；2026年具体外部行政办理机关及手续类别留 U，不照搬旧法用语。来源 L28。

**F06 · 505号令，第2条**｜范围：法人或其他组织**面向社会公众**，每场次**预计**1000人以上，且属于该条列举的体育竞赛、文艺演出、展览展销、游园等、招聘会等活动；主体：承办者；阶段：活动分类；性质：构成适用范围的累积条件；日常业务范围内的影剧院、音乐厅、公园、娱乐场所活动明确排除。输出：命中/不命中第505号令第2条；不能凭“校内活动很热闹”或“人数1000”单项触发。来源 L505。

## 3. U｜明确的缺口和获取机关（不得推算）

- **U01 校本规程全文/有效性**：需要学校党委保卫部或校办正式提供《成都理工大学安全与消防管理规程》成理校发〔2016〕3号的完整版本、后续修订/废止信息，必要时由学校档案馆提供认证文本。目前只有校方其他文件的引用。
- **U02 校内大型活动“多大算大型”、受理材料、签批层级和提前时限**：需要成都理工大学保卫处治安科、消防科现行大型活动治安/场地/消防现场检查实施细则和正式表单；仅凭职责网页不足以确定人数阈值。
- **U03 2026外来施工人员入校与普通访客关系**：需要学校校园安全勤务中心、校园规划与建设处现行施工人员名单/承包商报备/门禁流程。2022因公访客公告不自动替代。
- **U04 校内工程及动火“审批单据与有效期”**：需要学校消防科正式工程报备书、动火作业申请书、签批岗位、施工现场检查记录样式；2025通知仅证实需动火审批及现场监管。
- **U05 外部建设工程消防设计审查/验收/备案及2026有权机关**：需要当期有效法律、住建等有权部门规章及项目分类事实；第28号令的旧称谓不能独立解决。
- **U06 特定活动是否属于505号令列举项目、是否“面向社会公众”/预计人数、政府是否直接举办**：需要活动发起方的真实活动方案和主体证明；没有真实个案不能给 PASS/FAIL。
- **U07 源页直接可取回性**：学校官网直开HTTP 412，官方搜索索引可核条文；需要有权部门提供PDF/附件或开放直接获取，才可声称完整校规查验。

## 4. 分类及状态机边界（推导，受上述证据限制）

1. 活动先做 **505适用性判别**（活动类型 + 面向社会公众 + 每场预计人数 + 法定排除/特别主体）；命中则走公安许可；**28号令第15条另判校园大型活动/展览适用性**，命中则走学校消防现场检查；学校治安与场地审批独立保留。
2. 对活动状态至少分：校内活动申报/治安场地审批、学校消防待检查/合格、505公安申请待受理/受理/许可/不予许可、临时变更需同意/重新申请。不能压为单一“盖章通过”。
3. 对校园人员/施工至少分：因公访客门禁（历史来源，当前 U）、施工现场消防责任、校内工程备案审查、动火审批、施工中监管、竣工资料备案。进入校园的通行授权不等于可开始动火施工。
4. **反向解释**：校园内部大型活动即使不属于505号令，也可能触发28号令第15条；面向公众的千人文艺活动即使已有校内场地审批，仍可能须公安许可；是否学校活动的大型性无法由505的千人界线反向定义。
