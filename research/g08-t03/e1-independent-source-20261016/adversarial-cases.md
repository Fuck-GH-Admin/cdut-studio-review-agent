# G08-T03｜真正单一事实差异的最小反例（独立 E1）

> 本文件只使用本轮独立官方外部事实，不读取 C 母版、D Gold 或旧 E 缺陷位置；以下设定的人员、日期、案件均为 **S（封闭模拟）**，不是真实学校案件。预期结果标 F 时仅指特定官方指南/规范可支持的规则；未知标 U，不外推。

## 测试准则
每组 P/Q **仅改变表中写出的一个条件**，其他包括当事人、所属学校、提交内容、文本材料、经办操作和时间一律不变；不依据“看起来差不多”自称单变量。不得把结果说成现行成都理工校内功能测试。

| 对 | 固定模拟场景（S） | P→Q：唯一改变事实 | 可区分结果与范围 |
|---|---|---|---|
| A01 | 烟台职业学院平台，首次处理结果已反馈、即将评价，其他条件恒定 | 首次评价“满意”→“一般”（均按平台要求操作） | 满意→直接办结；一般→应填原因并可选办结/继续办理，而非自动必重办。F：SD01/02 第5项 |
| A02 | 同校首次评价“不满意”且已填原因，未变化 | 诉求人点“办结”→点“继续办理” | 前者办结；后者二次上报且学校需再次反馈。F：SD01/02 第5项 |
| A03 | 同校，评价值均“不满意”、理由完整，操作一致 | 评价阶段“首次反馈后”→“二次处理后” | 首次能选择办结/继续办理；二次导向最终反馈与已办结查看，不能无证据开放第三轮选择。F：SD01/02/03 |

| A05 | 同校，用户注册、填报、内容相同 | 所属单位选择“本校”→“其他高校” | 本校可处理/能路由；误选外校不应当被认定是本校有效受理。F：SD02/03 |

## 最小反例的失败定义（不是原 C 的错误定位）

1. 把“一般/不满意”统一自动送二次办理，忽略可选“办结” → A01/A02 可区分。
2. 将二次“不满意”误设成无限次继续办理或误写为“满意办结” → A03。
3. 把提交时间、反馈时间或第一次/第二次评价混作同一个阶段时钟 → A03/A07/A08/A09。
4. 用“办理中”单一标志允许所有撤回 → A04。
5. 不检查所属学校及职权边界，把外校业务清单硬灌本校 → A05/A06/A12。
6. 对本校信箱强制身份证、强制带“继续办理”按钮 → A10/A11/A12。
7. 把普通信箱投诉直接替代法定学生申诉或信访复查 → A11/A13/A14/A15。
8. 引用过期省规范或未经核对的2017校规来决定2026现行计算口径 → A16。

## 反向解释 / 可证伪条件

- R1：SD04（2025 简版）未列“一般/不满意”分支，可能只是省略，而非政策改变；要能推翻 SD01/03 的阶段逻辑，需2026有权运营方完整版及演示记录。
- R2：二次不满意后的“最终反馈”可能是内部完结流程，不能直接断言诉求人被视为满意；需平台状态字段定义证据。
- R3：成都理工独立邮件信箱理论上可能存在后台工单，但公开指南不足以证实与山东三值评价一致；需校党政办公室授权文本。
- R4：2017校规与教育部解释冲突可能由后续修订消除，也可能是过时网页留存；需当期学校制度公示与有权部门确认。
- R5：信访制度中复查/复核与校内学生处分复查属于不同法律通道；有权机构可能因诉求法律性质拒收错误路径，需办事事项性质先行核实。
